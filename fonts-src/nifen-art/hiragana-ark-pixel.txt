# CHANGES MADE HERE (the donor drawing is otherwise unchanged, pixel for pixel):
#   1. Every letter is moved up one row: the donor ink sits on rows -2..8, the kana cell of this
#      typeface on rows -1..9.
#   2. Each letter keeps the column the donor drew it in (full-size letters: ink in columns
#      0..10, the widened full-width cell; no column or row is removed). The small letters are
#      centred in the cell (at most 9 columns and 9 rows).
#   3. Where a Regular stroke would be two pixels wide (a 2x2 block) one corner pixel is removed.
# The note above each letter says which of these steps changed it.
#
# Bold is derived by the rule of this typeface (Regular merged with Regular shifted one pixel to
# the right); the Bold drawings that correct that rule are in bold-overlays-ark-pixel.txt.
