# 내보내기와 파이프라인 연동

**내보내기 시스템**은 프로젝트를 게임 제작 파이프라인에서 쓰는 에셋으로 바꿔 줍니다. 결과물은
**PNG** 한 장, **애니메이션 GIF**, **스프라이트시트**, 또는 촘촘하게 배치한 **텍스처 아틀라스**입니다.
여기에 **Aseprite 방식 JSON** 메타데이터(선택 사항)와, **Unity**와 **Godot**에 바로 가져다 쓸 수
있는 **엔진 프리셋**을 함께 만들 수 있습니다. 내보내기 대화 상자에서 대상 하나를 내보내거나, 일괄
내보내기 패널에 여러 대상을 쌓아 한꺼번에 내보내거나, `pixelart-export` 명령줄로 전 과정을 GUI 없이
실행할 수 있습니다. 어느 방법을 쓰든 결과는 **바이트까지 똑같습니다**. 내보내기 대화 상자는
**파일 ▸ 내보내기…** 또는 **Ctrl+Shift+E**로 엽니다.

> **바이트 단위로 재현되는 내보내기.** 내보내기는 **항상 같은 결과**를 냅니다. 입력 문서와 매개변수가
> 같으면 출력 바이트는 매번 똑같습니다. 프레임은 정해진 순서로 처리하고, GIF는 고정된 공유 팔레트를
> 쓰며 디더링을 끄고, 인코더 버전도 고정되어 있기 때문입니다. GUI와 CLI는 동일한 엔진을 구동하므로,
> 한 문서를 GUI로 내보낸 결과와 CLI로 내보낸 결과는 **바이트까지 일치합니다**. 이 보장은 *같은 환경
> 안에서*(툴체인을 고정했을 때)만 성립하며, 서로 다른 컴퓨터 사이에서는 보장되지 않습니다.

| 단축키 | 동작 |
| --- | --- |
| **Ctrl+Shift+E** | 내보내기 대화 상자를 엽니다. |

## 래스터 내보내기(PNG / GIF)

- **PNG**는 **프레임 0**을 RGBA 이미지 한 장으로 내보냅니다. 정지 이미지용 대상입니다.
- **GIF**는 애니메이션을 내보냅니다. 모든 프레임을 순서대로, 각 프레임마다 **프레임별 지속 시간**
  ([애니메이션 타임라인](animation-timeline.md)에서 정한 지속 시간)만큼 보여 주며, 반복 횟수, 프레임
  처리 방식, 투명도가 파일에 기록됩니다. 모든 프레임은 **고정된 팔레트 하나**를 공유합니다. 이 팔레트는
  애니메이션 전체를 대상으로 중앙값 분할, 즉 median-cut 방식으로 색상을 줄여 만듭니다. 디더링은 **꺼져**
  있어서 GIF의 바이트가 항상 같습니다.

> **GIF 반복 횟수.** `--loop` 옵션(CLI)과 **반복 횟수** 필드(대화 상자)는 GIF를 몇 번 반복할지 정합니다.
> **`0`은 무한 반복입니다.**

## 스프라이트시트와 텍스처 아틀라스

- **스프라이트시트**는 모든 프레임을 **균일한 격자**에 행 우선(row-major) 순서로 배치합니다. 프레임
  `k`는 열 `k % columns`, 행 `k // columns`에 놓이며, 스프라이트 사이 **여백**은 설정할 수 있고
  바깥 여백은 없습니다. 열 수로 시트의 모양을 조절하세요.
- **텍스처 아틀라스**는 공용 **MaxRects** 패커로 프레임을 촘촘하게 채워 넣습니다(회전은 꺼져 있으므로
  스프라이트는 항상 축에 맞춰 정렬됩니다). 프레임마다 내용이 다를 때 공간 효율이 좋은 방식입니다.

> **아틀라스 크기 상한.** 아틀라스는 플랫폼의 **8K** 크기 상한 안으로 제한됩니다. 스프라이트 묶음이
> 그 상한 안에 들어가지 않으면 내보내기는 명확한 아틀라스 오류와 함께 **깔끔하게 실패합니다**.
> 조용히 겹치거나 잘리거나 비정상 종료되는 일은 없습니다. 여백, 프레임 크기, 프레임 수를 줄여서 다시
> 시도하세요.

## JSON 메타데이터

스프라이트시트와 아틀라스 내보내기는 **Aseprite *Array*** 형식의 **JSON 메타데이터 사이드카**(이미지
옆에 놓이는 별도 파일)를 함께 만들 수 있습니다. 이 파일은 `frames[]` 배열(각 프레임의 사각형, 원본
크기, 지속 시간)과 프레임 **태그** 및 프레임별 지속 시간을 담은 `meta{}` 블록으로 이루어집니다.
JSON은 **항상 같은 형태**로 만들어집니다. 키는 정렬하고, 구분자는 고정하며, 좌표는 정수이므로 다시
읽어도 값이 그대로이고 diff도 깔끔합니다. 대화 상자의 **JSON 메타데이터 쓰기** 확인란으로 켜고 끄거나,
CLI에서는 `--json` / `--no-json` 옵션으로 정합니다(기본은 켜짐).

## 엔진 프리셋(Unity / Godot)

이미지와 JSON 외에 **엔진용 프리셋**도 함께 만들 수 있어, 에셋을 프로젝트에 바로 넣을 수 있습니다.

| 프리셋 | 작성하는 내용 |
| --- | --- |
| **Unity** | 스프라이트 `.meta` 사이드카 파일 — 스프라이트 모드 **Multiple**, `pixelsPerUnit`, 피벗, `filterMode = Point`(선명한 픽셀, 쌍선형 보간 없음). |
| **Godot** | 내보낸 프레임으로 만든 `SpriteFrames` `.tres` 리소스(Godot 4.2). |

프리셋은 대화 상자에서 고르거나, CLI에서는 `--preset unity` 또는 `--preset godot` 옵션을 넘깁니다.
기본값인 `--preset none` 옵션은 프리셋을 만들지 않습니다. 프리셋 파일은 이미지와 같은 프레임 배치
정보에서 항상 같은 결과로 만들어집니다.

## 일괄 내보내기

**일괄 내보내기 패널**은 **여러 대상을 한 번에** 대기열에 올립니다. 예를 들어 한 프로젝트에서 PNG,
GIF, Unity 아틀라스를 한 번의 실행으로 만들 수 있습니다. 일괄 내보내기는 **실패해도 계속 진행**합니다.
대상 하나가 실패하면(예: 크기에 맞지 않는 아틀라스) 나머지 대상은 그대로 내보내지고 실패는 해당
대상에만 보고되므로, 문제가 있는 대상 하나 때문에 일괄 작업이 중단되는 일은 없습니다.
**모두 내보내기** 버튼은 활성 탭의 문서를 대기열의 모든 대상에 한 번의 실행으로 내보냅니다.

## 내보낸 결과물을 라이브러리에 등록하기

내보내기 대화 상자에는 **에셋 라이브러리에도 추가** 확인란이 있어, 내보낸 결과물을
[에셋 라이브러리](asset-library.md)에 내보내기와 같은 단계에서 등록할 수 있습니다. 기본값이 아니라
직접 선택하는 옵션입니다. 이 옵션을 켜면 내보내기에 성공한 뒤 공용 **에셋 등록** 창(이름, 종류,
태그)이 열리고, 켜지 않으면 라이브러리를 전혀 건드리지 않고 이 옵션이 생기기 전과 똑같이 내보냅니다.

## 응답성

모든 내보내기 작업은 **GUI 스레드와 별개로** 백그라운드 작업 스레드에서 실행되며, **취소할 수 있는 진행률
표시**가 함께 나타납니다. 그래서 큰 애니메이션이나 아틀라스를 내보내도 창이 멈추지 않습니다.
내보내기는 문서를 **읽기만** 하므로 문서를 바꾸지 않고 실행 취소 단계도 만들지 않습니다.

> **큰 대상 하나를 취소할 때.** 취소는 대상 사이에서는 바로 적용됩니다. 큰 대상 하나를 **인코딩하는
> 도중**에 취소하면 반응이 더 느립니다. 진행 중인 인코딩이 끝난 뒤에야 취소가 확인되기 때문입니다.

## `pixelart-export` 명령줄

자동화와 CI를 위해 `pixelart-export`는 GUI 없이 **동일한** 내보내기 경로를 실행하므로, 같은 문서와
매개변수에서 나온 출력은 GUI 내보내기와 바이트까지 일치합니다. `.pixproj` 파일은 앱이 쓰는 것과
같은 프로젝트 로더로, 방어적으로 검증하며 읽습니다.

```
pixelart-export --input PROJECT.pixproj --format FORMAT --output OUT [options]
```

| 옵션 | 의미 |
| --- | --- |
| `--input PATH` | **(필수)** 내보낼 원본 `.pixproj` 프로젝트. |
| `--format FORMAT` | **(필수)** `png`, `gif`, `sprite-sheet`, `atlas` 중 하나. |
| `--output PATH` | **(필수)** 출력 이미지 경로. |
| `--preset PRESET` | 엔진 프리셋: `none`(기본), `unity`, `godot`. |
| `--columns N` | 스프라이트시트 열 수. |
| `--padding N` | 스프라이트 사이 여백(픽셀). |
| `--loop N` | GIF 반복 횟수(`0` = 무한 반복). |
| `--tag NAME` | 이름이 지정된 프레임 태그의 구간만 내보냅니다(기본: 문서 전체). |
| `--json` / `--no-json` | 스프라이트시트/아틀라스 JSON 사이드카를 만듭니다(기본: 켜짐). |

**종료 코드:** `0` 성공, `1` 내보내기 / 패킹 / 쓰기 오류(예: 크기에 맞지 않는 아틀라스, 파일 시스템
쓰기 실패), `2` 잘못된 인수, 또는 형식이 잘못되었거나 읽을 수 없는 입력 프로젝트.

> **GUI와 동일한 경로.** CLI와 대화 상자는 같은 엔진을 호출하므로, 먼저 대화형으로 내보내기를 시험해
> 본 다음 같은 매개변수를 옵션으로 넘겨 빌드 스크립트에서 그대로 재현할 수 있습니다.

## 다루지 않는 내용

- **APNG**(애니메이션 PNG)는 **보류** 중입니다. 이번 릴리스는 정지 PNG(프레임 0)와 애니메이션
  GIF를 내보냅니다.
- **컴퓨터 사이의 바이트 일치** — 바이트 재현성 보장은 *같은 환경 안에서*(툴체인을 고정했을 때)만
  성립하며, 다른 컴퓨터의 툴체인은 다른 바이트를 만들 수 있습니다.
- **큰 대상 하나의 인코딩 도중 세밀한 취소** — 취소는 대상 사이에서 확인되며, 대상 하나의 인코딩
  중간에서는 확인되지 않습니다.

## 관련 주제

- 내보내기를 스크립트로 구성한 파이프라인의 일부로 자동화하는 방법은
  [자동화와 스크립팅](automation-and-scripting.md)을 참고하세요.
