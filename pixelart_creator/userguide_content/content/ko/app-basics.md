# 시작하기와 작업 공간

![PixelArt Creator](pac-logo.png)

**PixelArt Creator**에 오신 것을 환영합니다. PixelArt Creator는 8K 캔버스, 비파괴 레이어 시스템,
애니메이션 타임라인, 타일셋/타일맵 편집기, 내보내기 파이프라인, 자동화와 스크립팅, 시각 보조,
클라우드 협업을 갖춘 데스크톱 픽셀 아트 스튜디오입니다. 이 주제는 작업 공간을 소개하여
가이드의 나머지 내용을 이해하기 쉽게 해 줍니다.

## 메인 창 한눈에 보기

- **메뉴 막대**(위쪽) — 모든 명령으로 들어가는 입구이며, 명령은 **파일**, **편집**, **보기**,
  **클라우드**, **도움말** 같은 메뉴로 묶여 있습니다. 지금 읽고 계신 앱 내 사용자 가이드는
  **도움말 ▸ 사용자 가이드**에서 열거나 **F1** 키를 눌러 열 수 있습니다.
- **캔버스**(가운데) — 그림을 그리는 면입니다.
  [캔버스: 확대/축소, 이동, 격자](canvas-and-view.md)를 참고하세요.
- **도킹 패널**(양옆) — 레이어 패널, 애니메이션 타임라인, 타일셋 패널, 클라우드/협업 패널이
  있습니다. 대부분의 패널은 켜고 끌 수 있으며 작업 방식에 맞게 배치할 수 있습니다.
- **상태 표시줄**(아래쪽) — 좌표 표시, 백그라운드 작업(내보내기, 재생 준비, 클라우드 저장)의
  진행 표시, 짧은 알림이 나타납니다.

## 문서와 탭

열려 있는 그림 하나하나가 **문서**이며, 각 문서는 자기만의 **탭**에 표시됩니다. 문서에는 크기,
색상 모드(**RGBA** 또는 **인덱스**), 팔레트, 레이어 트리가 있고, 애니메이션을 만들면
프레임 목록도 있습니다. 여러 문서를 동시에 열어 둘 수 있습니다.
[여러 캔버스(아트보드)](multi-canvas.md)를 참고하세요. 문서는 **`.pixproj`** 프로젝트 파일로
저장됩니다. 이 파일은 검증되고 버전이 관리되는 저장 형식이며, 앱 전체(클라우드 계층 포함)가
이 형식을 사용합니다.

## 실행 취소와 다시 실행

그리기, 레이어 변경, 변형, 프레임 편집, 자동화 실행처럼 거의 모든 편집은 문서의 **실행 취소
스택**에 **정확히 한** 단계로 쌓입니다. **실행 취소**는 마지막 단계를 되돌리고, **다시 실행**은
그 단계를 다시 적용합니다. 실행 취소 내역은 **탭마다 따로** 있으므로 한 문서에서 실행 취소해도
다른 문서에는 영향이 없습니다. 몇몇 동작은 편집이 아니라 보기 상태이므로 의도적으로 실행
취소할 수 없습니다. 프레임을 선택하거나 스크럽하기, 어니언 스킨 전환, 안내선 추가, 클라우드/협업
패널 열기가 여기에 해당합니다.

## 테마(스타일, 라이트, 다크)

애플리케이션의 모양과 관련된 모든 설정은 **테마** 메뉴에 있습니다. 어떤 선택이든 즉시
적용되며, 다음에 애플리케이션을 시작할 때도 유지됩니다.

- **스타일** — 세 가지 시각 스타일이 있는 하위 메뉴입니다. **Washi & Kintsugi**(기본값),
  **Edo Night**, **Arcade Kikko**가 있으며, 각각 패널, 대화 상자, 테두리, 창의 패턴 영역까지
  갖춘 완전한 모양입니다.
- **라이트** / **다크** — 스타일과 별개로 고르는 색상 모드입니다. 모든 패널, 대화 상자, 오버레이와
  이 사용자 가이드는 두 모드에서 모두 올바르게 표시되고 읽기 쉽습니다. 색상은 역할별로 한 번만
  정의되므로 테마는 어디서나 일관됩니다.
- **시스템 글꼴 사용** — 인터페이스를 기본 제공 픽셀 서체(Nifen Art)에서 운영 체제의 인터페이스
  글꼴로 바꿉니다.
- **픽셀 퍼펙트 인터페이스** — 기본적으로 켜져 있습니다. 인터페이스를 정수 배율로만 조정하므로
  배율이 정수가 아닌 디스플레이(예: 125% 또는 150%)에서도 픽셀 아트가 또렷하게 유지됩니다. 변경
  사항은 다음에 애플리케이션을 시작할 때 적용됩니다.

## 버전과 정보

창 제목에는 항상 **PixelArt Creator**와 실행 중인 버전, 즉 현재 빌드의 정확한 번호가 표시되므로
따로 찾아볼 필요가 없습니다. 더 자세한 내용은 **도움말 ▸ PixelArt Creator 정보**를 선택하세요
(macOS에서는 종료 항목 옆의 애플리케이션 메뉴에 있습니다. 플랫폼이 그 위치에 항목을
둡니다). 정보 대화 상자에는 앱 이름, 버전(직접 복사할 수 있도록 선택 가능), 라이선스,
소스 저장소, 설명서 사이트, 릴리스 페이지 링크, 그리고 **복사** 버튼이 표시됩니다. **복사**
버튼은 버전과 함께 운영 체제, Python, Qt/PySide6 버전을 한 줄로 클립보드에 넣어 주므로 버그
보고서에 그대로 붙여 넣을 수 있습니다.

## 언어

인터페이스는 완전히 번역할 수 있습니다. 사용 중인 언어를 바꾸면 모든 메뉴, 레이블, 메시지가
바로 새 언어로 바뀌며 다시 시작할 필요가 없습니다. 이 사용자 가이드의 틀(제목, 섹션 레이블,
검색 상자, 탐색)도 사용 중인 언어를 따릅니다. 가이드 내용은 번역본이 포함되어 있으면 해당
언어로 표시되고, 없으면 기본(영어) 텍스트로 대체됩니다.

## 키보드 단축키

다음은 애플리케이션 키보드 단축키의 전체 표입니다. 모든 도구 키, 두 가지 전환, 선택 영역을 지우는
두 가지 방법, 핵심 파일/편집/도움말 동작이 들어 있습니다. 이 가이드에서 키보드 단축키를 언급하는
다른 모든 페이지는 단축키를 되풀이하지 않고 이 표를 가리킵니다.

| 단축키 | 동작 |
| --- | --- |
| **A** | 연필 도구 — 자유롭게 픽셀을 칠합니다. |
| **Shift+A** | 스포이드 도구 — 캔버스에서 색상을 가져옵니다. |
| **Q** | 지우개 도구. |
| **S** | 사각형 도구. |
| **W** | 선 도구. |
| **Shift+W** | 타원 도구. |
| **D** | 사각형 선택 도구. |
| **F** | 채우기 도구. |
| **Shift+F** | 디더링 도구. |
| **E** | 올가미 선택 도구(자유 형태). |
| **Shift+E** | 마술봉 선택 도구(인접한 같은 색 영역). |
| **Shift+S** | **채워진 도형** 전환. 사각형 도구와 타원 도구가 함께 사용합니다. |
| **Shift+R** | 열려 있는 모든 탭의 캔버스 보기에서 **픽셀 퍼펙트** 전환. |
| **Shift+Q** | 선택 영역의 내용 지우기. |
| **Delete** | 선택 영역의 내용 지우기(같은 동작의 두 번째 단축키). |
| **Ctrl+N** | 새 문서. |
| **Ctrl+O** | 기존 프로젝트 열기. |
| **Ctrl+S** | 활성 프로젝트 저장. |
| **Ctrl+Z** | 마지막으로 되돌릴 수 있는 작업 실행 취소. |
| **Ctrl+Y** | 마지막으로 실행 취소한 작업 다시 실행. |
| **F1** | 이 사용자 가이드 열기. |

위의 도구 키 열한 개는 일부러 홈 로우와 그 주변에 배치했으므로, 그리는 동안 손이 타자
자세에서 벗어날 필요가 없습니다. **Shift+Q**와 **Delete** 키는 선택 영역의 내용을 지우는 같은
동작을 하므로, 손이 가까이 있는 쪽을 사용하면 됩니다.

몇 가지 단축키는 해당 기능을 알아야 의미가 있으므로 그 기능이 설명된 페이지에 있습니다.
내보내기를 여는 **Ctrl+Shift+E**는 [내보내기와 파이프라인 연동](export-and-pipeline.md)을
참고하세요. 캔버스를 확대/축소하는 **Ctrl++** / **Ctrl+-** 단축키와, 휠이나 가운데 버튼으로
이동, 확대/축소, 색상 선택을 하는 포인터 제스처는 [캔버스](canvas-and-view.md)를 참고하세요.
**Ctrl+A** / **Ctrl+I** / **Ctrl+Shift+A** / **Shift+H** / **Shift+V** 단축키와 선택 영역 끌기
제스처는 [선택과 플로팅 이동/복사](selection-and-transform.md)를 참고하세요. 타임라인에서 쓰는
**Ctrl+wheel**, **Ctrl+middle-click**, **Ctrl+left-click**, **Ctrl+right-click** 제스처는
[애니메이션 타임라인](animation-timeline.md)을 참고하세요. **Space** 키는 애니메이션 재생/일시
정지를 전환하며 메뉴 단축키가 전혀 아닙니다. 프레임이 둘 이상인 문서가 열려 있을 때만
동작합니다. **Esc** 키는 진행 중인 동작(대개 플로팅 선택 영역 이동)을 취소하고 **Enter** 키는
확정합니다. 정확히 어디까지 해당하는지는
[선택과 플로팅 이동/복사](selection-and-transform.md)를 참고하세요.
