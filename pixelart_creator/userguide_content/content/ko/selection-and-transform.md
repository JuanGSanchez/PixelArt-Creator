# 선택과 플로팅 이동/복사

영역을 선택하면 작품의 일부만 작업할 수 있습니다. **플로팅 선택 영역**을 쓰면 활성 선택 영역
안의 색상을 집어 들어 **실시간 비파괴 미리 보기**로 이동하거나 복사할 수 있습니다. 플로팅
선택 영역 *아래에* 있는 픽셀은 확정하기 전까지 **바뀌지 않으므로**, 이동은 언제든 위치를 다시
잡거나 포기해도 안전합니다.

Aseprite, Pro Motion NG, Pixelorama, Krita에서 익숙한 동작, 즉 들어 올리고, 끌고, 놓는 방식입니다.

> **활성 레이어에서만 동작합니다.** 플로팅 이동/복사는 **활성 레이어**에서 동작합니다
> ([레이어 패널](layers.md) 참고). 인덱스 문서에서는 하나뿐인 인덱스 레이어가 해당됩니다.
> 다른 레이어는 건드리지 않습니다.

## 선택 영역 만들기

선택 도구로 작업할 영역을 정의합니다.

| 도구 | 선택하는 대상 |
| --- | --- |
| **사각형 선택** | 끌어서 그리는 직사각형 영역. |
| **올가미 선택** | 둘레를 따라 자유롭게 그리는 영역. |
| **마술봉** | 누른 위치 아래에서 이어진 비슷한 색상의 영역. |

**선택 영역의 수명.** 위의 세 가지 선택 도구 중 하나로 전환하면 현재 선택 영역이 항상
**버려지고** 새로 시작합니다. 새 선택 영역은 이전 선택 영역의 모양을 물려받지 않습니다.
그 외의 도구(연필, 지우개, 채우기…)로 전환하면 현재 선택 영역이 대신 **유지되므로**,
마스크로 제한된 그리기가 계속 동작합니다. 다른 도구로 그려도 붓질이 선택 영역 안으로
잘려 나갑니다.

위의 세 가지 선택 도구 중 하나가 활성일 때는 **Shift** 키와 **Alt** 키가 캔버스의 다른 곳과 다른
의미를 갖습니다. 아래의 [화면 이동과 선택 영역 만들기의 차이](#panning-vs-building-a-selection)를
참고하세요.

| 수정 키 | 선택 도구가 활성일 때의 결과 |
| --- | --- |
| **Shift**+끌기 | 현재 선택 영역에 **추가**합니다. |
| **Alt**+끌기 | 현재 선택 영역에서 **뺍니다**. |

### 화면 이동과 선택 영역 만들기의 차이

| 제스처 | 결과 |
| --- | --- |
| **Shift+left-drag** | 캔버스 화면을 이동합니다. **단**, 선택 도구가 활성일 때는 위 표에서 설명한 대로 이동하지 않고 선택 영역에 **추가**합니다. |

### 캔버스 전체 선택, 반전, 해제

| 단축키 | 동작 |
| --- | --- |
| **Ctrl+A** | 캔버스 전체를 선택합니다. |
| **Ctrl+I** | 현재 선택 영역을 반전합니다. |
| **Ctrl+Shift+A** | 선택을 해제합니다(현재 선택 영역을 지웁니다). |

선택 영역 자체가 아니라 선택 영역의 **내용**을 지우는 것은 **Shift+Q**와 **Delete**라는 별도
단축키를 가진 다른 동작입니다. [애플리케이션 기본](app-basics.md)의 표를 참고하세요.

## 들어 올리기와 이동(끌기)

플로팅은 이미 활성인 선택 영역을 그대로 들어 올립니다. 새 선택 영역 모양을 만드는 것이 아니라
이미 가진 마스크를 재사용합니다.

1. 선택/이동 도구가 활성인 상태에서 활성 선택 영역 **안쪽을 누릅니다**. 마스크된 픽셀이
   플로팅 미리 보기로 들어 올려집니다.
2. **끕니다.** 플로팅된 색상이 커서를 따라가며, 실시간 미리 보기에서 원래 영역은 **투명으로
   지워진 것**으로 보입니다(인덱스 모드에서는 인덱스 0).
3. 아래의 실제 픽셀은 **아직 수정되지 않으며** 미리 보기만 바뀝니다.

활성 선택 영역 **바깥**을 누르면 들어 올리지 **않고** 평소처럼 새 선택 영역을 시작합니다.

## 이동 대신 복사: Ctrl 키 누르기

끄는 동안 **Ctrl** 키를 누르고 있으면 플로팅이 **복사**로 바뀝니다.

- **원본은 그대로 남고**(비워지는 곳이 없음),
- 색상의 **사본**이 커서로 플로팅됩니다.

복사 모드 커서/표시가 복사 중임을 알려 줍니다. 끄는 **도중에** Ctrl 키를 누르거나 떼어 이동과
복사를 오갈 수 있습니다.

> **복사 수정 키는 Ctrl 키뿐이며 Alt 키가 아닙니다.** 복사는 **Ctrl 키 단독**입니다. **Alt 키는 복사 수정
> 키가 아닙니다.** 안쪽에서 Alt 키를 누른 채 끌면 선택 영역 만들기의 **빼기** 제스처이며, 그
> 의미가 유지됩니다. 안쪽 끌기에서 **Ctrl+Alt**를 누르면 복사가 아니라 Alt 빼기로
> 처리됩니다. 복사하려면 **Ctrl** 키만 누르세요.

| 안쪽 끌기 | 결과 |
| --- | --- |
| *수정 키 없음* | 선택 영역을 들어 올려 **이동**합니다(확정 시 원본이 비워짐) |
| **Ctrl** | 선택 영역을 **복사**합니다(원본 유지) |
| **Alt** | 선택 영역에서 **뺍니다**(선택 영역 만들기 제스처) |
| **Shift** | 선택 영역에 **추가**합니다(선택 영역 만들기 제스처). 선택 도구가 활성이 아닐 때는 **Shift+left-drag**는 추가하는 대신 화면을 이동합니다. 위의 [화면 이동과 선택 영역 만들기의 차이](#panning-vs-building-a-selection)를 참고하세요. |

## 확정 또는 취소

플로팅은 다음 중 하나가 일어나면 **확정**됩니다.

- 마우스 버튼을 **놓을 때**,
- **Enter / Return** 키를 누를 때,
- **도구를 전환할 때**(또는 캔버스 탭을 전환할 때).

확정하면 변경이 **정확히 실행 취소 가능한 한 단계**로 적용됩니다.

- **이동** — 원본이 투명으로 기록되고(인덱스 모드에서는 인덱스 0) 색상이 목적지에 찍힙니다.
- **복사** — 색상이 목적지에 찍히고 원본은 그대로 둡니다.

확정한 뒤에는 선택 영역 마스크가 **목적지로 따라갑니다**.

**Esc** 키를 누르면 **취소**됩니다. 플로팅은 버퍼에 아무것도 쓰지 않았으므로 취소하면 이동 전
캔버스가 **정확히** 복원되고 실행 취소 항목은 **남지 않으며**, 선택 영역 마스크는 들어 올리기
전 위치로 돌아갑니다.

> **끌지 않고 누르기만 하면 아무 비용도 들지 않습니다.** 오프셋 0으로 확정하는 것(이동 없이
> 선택 영역 안쪽만 누르는 것)은 아무 일도 하지 않으며 실행 취소 단계도 만들지 않습니다.

목적지에 이미 픽셀이 있으면 **기존 픽셀을 덮어쓰시겠습니까?** 대화 상자가 먼저 묻습니다.
**계속**을 선택하면 평소처럼 확정이 적용되고, **취소**를 선택하면 아무것도 적용하지 않고
플로팅을 현재 오프셋에 활성 상태로 둡니다. **"이 프로젝트에서는 다시 묻지 않음"** 확인란을 선택해도
실제로 수락한 경우에만 그 설정이 저장됩니다. 선택하고 취소하면 아무것도 저장되지 않습니다.

## 캔버스 밖 가장자리

플로팅을 **일부 또는 전부 캔버스 밖으로** 끌 수 있습니다. 확정하면 캔버스 밖 픽셀은 **버려지며**
(반대편으로 넘어가지 않음), 오류 없이 작품을 가장자리까지 밀 수 있습니다. 이동의 경우, 얼마나
멀리 끌었는지와 관계없이 범위 안에 있는 원본 전체가 비워집니다.

## 실행 취소, 다시 실행, 렌더링

- 확정된 이동 또는 복사는 실행 취소 **한** 단계입니다. **실행 취소**하면 이동 전 버퍼가 정확히
  복원되고 **다시 실행**하면 다시 적용됩니다.
- 플로팅 미리 보기는 어떤 확대/축소에서도 **최근접 이웃, 안티앨리어싱 끔**으로 렌더링되며,
  **라이트**와 **다크** 테마에서 모두 읽기 쉽습니다.
- 실시간 끌기 미리 보기는 플로팅이 닿는 영역만 갱신하므로, 8K 캔버스에서도 16 ms / 60 fps
  프레임 예산 안에 머뭅니다.

## 문서 전체 변형

**이미지 ▸ 배율 조정…**, 90° 회전 두 가지, 뒤집기 두 가지는 선택 영역이 없을 때마다 **문서 전체**에
적용됩니다. 모든 프레임의 모든 레이어와 마스크가 대상입니다. 활성 선택 영역이 있으면 이전과
똑같이 이 동작들이 활성 레이어의 마스크된 영역만 변형합니다.

| 단축키 | 동작 |
| --- | --- |
| **Shift+H** | 선택 영역(또는 문서 전체)을 가로로 뒤집습니다. |
| **Shift+V** | 선택 영역(또는 문서 전체)을 세로로 뒤집습니다. |

RotSprite는 유일한 예외입니다. 회전해도 버퍼의 크기가 바뀌지 않아 더 넓은 범위가 필요한 적이
없으므로, 선택 영역이 있든 없든 항상 활성 레이어만 변형합니다.

> **큰 변형은 먼저 확인합니다.** 리샘플링 결과와 실행 취소용으로 보관하는 버퍼를 합한 크기가
> 506.25 MiB(8K 캔버스 전체 RGBA 데이터 네 장 분량)를 넘으면
> **대규모 변형 확인** 대화 상자가 나타납니다. 이 대화 상자는 무엇이든 실행하기 전에 예상 메모리 사용량을
> 정확히 알려 줍니다. **취소**가 기본
> 버튼이므로 Return 키를 눌러도 변형이 시작되지 **않으며**, **계속**을 일부러 선택해야 합니다.
> 거절하면 문서는 전혀 건드리지 않고 실행 취소 스택에도 아무것도 쌓이지 않습니다. 그 임계값
> 아래에서는 대화 상자가 전혀 나타나지 않습니다.

문서 전체 변형이 실행되기 시작하면 **문서 변형 중** 진행 대화 상자가 버퍼 단위로 진행 상황을
보여 주며, 언제든 취소할 수 있습니다. **취소** 버튼, Escape 키, 창의 닫기 컨트롤 모두 동작합니다.
취소는 원자적입니다. 이미 몇 개의 버퍼를 리샘플링했든 문서는 정확히 원래대로 남고 실행 취소
스택에는 아무것도 쌓이지 않습니다.

## 다루지 않는 내용

- 선택 영역이 *플로팅 중일 때* **회전하거나 배율 조정**하기 — 먼저 이동을 확정한 뒤 변형 도구를
  사용하세요.
- **모든 레이어 이동** 방식 — 플로팅은 활성 레이어에서만 동작합니다.
- 플로팅을 **문서 간에 끌기**, 또는 플로팅을 `.pixproj`에 저장하기 — 플로팅은 일시적인 편집
  상태이므로 항상 먼저 확정하거나 취소합니다.
