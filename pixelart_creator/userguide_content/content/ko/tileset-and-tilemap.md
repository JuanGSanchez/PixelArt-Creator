# 타일셋, 타일맵, 자동 타일

**타일맵 시스템**은 원본 이미지를 재사용할 수 있는 **타일셋**으로 바꾸고, 그 타일로 **여러 레이어로
된 무한 맵**에 큰 레벨을 그릴 수 있게 합니다. 이미지를 인덱스가 매겨진 타일로 자르고, 칸에
스탬프로 찍거나 지우거나 채울 수 있습니다. **자동 타일**이 경계를 알아서 처리하며, 타일을 놓을 때
뒤집거나 회전할 수 있고, 맵 전체를 Tiled와 호환되는 JSON으로 **내보내고 가져올** 수 있습니다.
맵 편집은 모두 실행 취소 한 단계입니다.

> **논리 타일과 표시 타일.** 자동 타일은 사용자가 *놓는* 타일(**논리** 타일)과 *보이는* 타일(**표시**
> 타일)을 구분합니다. "벽" 타일 하나만 그리면 맵이 이웃 타일을 보고 알맞은 가장자리/모서리
> 변형본을 고릅니다. 저장되고 다시 열 때 복원되는 것은 논리적 배치이므로, 결과는 **항상 같고
> 되돌릴 수 있습니다**. 자동 타일을 끄면 논리 타일이 그대로 표시됩니다.

## 타일셋

**타일셋**은 크기가 같은 타일의 격자로 잘라 낸 원본 이미지입니다. **타일셋 편집기** 패널(타일맵 메뉴)을 열고
**타일맵 ▸ 이미지에서 새 타일셋…** 항목으로 타일셋을 추가하세요. 슬라이서는 지정한 **타일 너비**와 **타일 높이**, 선택 사항인 **바깥 여백**, 타일
사이 **간격**으로 이미지를 읽고, 만들어진 타일에 왼쪽에서 오른쪽, 위에서 아래 순서로 `0`부터
인덱스를 매깁니다.

- 각 타일은 원본 버퍼의 한 영역이므로, 타일셋은 사본 여러 개가 아니라 **이미지 하나로 이루어집니다**.
- **원본 타일을 편집하면** 모든 레이어에 놓인 그 타일의 모든 인스턴스에 **반영됩니다**. 타일을
  한 번 다시 그리면 레벨 전체가 갱신됩니다.
- 패널에는 잘라 낸 타일이 선택용 격자로 표시되며, 선택한 타일이 스탬프 도구로 그려지는
  타일입니다.

> **바깥 여백과 간격.** `margin`은 이미지 전체 둘레에서 건너뛰는 테두리이고, `spacing`은 타일
> **사이**에서 건너뛰는 틈입니다. 1px 틈을 두고 내보낸 시트는 보통 `spacing = 1`이 필요하며
> (틈이 가장자리도 감싸면 `margin = 1`도), 그래야 슬라이서가 각 타일에 정확히 맞습니다.

## 타일맵 그리기

**타일맵 캔버스**에서는 격자의 칸마다 타일 하나씩 그립니다. 타일셋 편집기 패널에서 타일을 고른 뒤
맵 도구를 사용하세요.

| 도구 | 설명 |
| --- | --- |
| **스탬프 도구** | 커서 아래의 칸에 선택한 타일을 놓습니다(끌면 연속으로 그립니다). |
| **타일 지우개** | 칸을 비웁니다. |
| **사각형 채우기** | 끌어서 지정한 사각형을 선택한 타일로 채웁니다. |

스탬프, 지우기, 사각형 채우기는 각각 **정확히 실행 취소 한 단계**이며, 실행 취소하면 이전 칸 상태가
정확히 복원됩니다. 기존 타일 근처에 그리면 **자동 타일**의 이웃 관계가 다시 계산되므로, 그리는
동안 경계가 계속 올바르게 유지됩니다.

### 뒤집기와 회전

스탬프를 찍기 전에 타일을 변형할 수 있습니다. **스탬프 가로로 뒤집기**와 **스탬프 세로로 뒤집기**는 타일을
거울처럼 뒤집고, **스탬프를 시계 방향으로 90° 회전**은 타일을 직각 방향 네 가지로 차례로 돌립니다. 변형은 놓인 칸마다
타일에 붙는 작은 플래그로 저장되므로, 타일을 뒤집거나 회전해도 **타일셋 항목이 늘어나지
않고** 손실 없이 복원됩니다. 변형은 정해진 순서(대각선, 가로, 세로)로 합성되어, 같은 조합은
항상 똑같이 그려집니다.

## 자동 타일

**자동 타일**은 각 칸의 *표시* 타일을 **여덟 이웃**으로부터 정합니다(Blob-47 방식: 이웃 8칸을
비트마스크로 읽되, 모서리는 맞닿은 두 가장자리가 모두 있을 때만 반영하여 서로 다른 타일 47개를 만듭니다). "지형"
타일 하나만 그리면 맵이 올바른 직선 가장자리와 안쪽/바깥쪽 모서리를 자동으로 채워 줍니다.

- 타일맵 레이어 패널의 **자동 타일 (Blob-47)** 확인란으로 자동 타일을 **전환**합니다. **켜 두면**
  칸을 그리거나 지우거나 사각형으로 채울 때 영향받는 칸 **및 그 이웃**도 다시 계산하여 경계가 항상 일관되게 유지되며, 이 모든 것이 같은
  실행 취소 한 단계 안에서 일어납니다.
- 계산은 논리적 배치와 이웃에 대해 **같은 입력에는 항상 같은 결과를 내는 순수 함수**이므로, 같은 맵은 언제나 같은
  표시 타일로 그려집니다.
- 자동 타일을 **끄면** 경계 계산 없이, 놓은 논리 타일이 그대로 표시됩니다.

## 레이어와 무한 맵

타일맵은 **여러 레이어**로 되어 있어 배경, 지형, 장식 레이어를 쌓고 각각 따로 그릴 수 있으며,
편집기의 나머지 부분과 같은 레이어 모델(추가 / 제거 / 순서 변경 / 표시 전환)을 사용합니다.
**타일맵 레이어** 패널이 스택을 관리하며, 보이는 레이어가 합성되어 표시됩니다.

맵 자체는 **무한**합니다. 칸은 **16×16 청크로 이루어진 희소 격자**로 저장되므로, 실제로 그린
영역만 메모리를 사용합니다. 맵 크기를 미리 정하지 않고도 원점에서 (어느 방향으로든) 멀리 떨어진
곳에 스탬프를 찍을 수 있고, 빈 영역은 비용이 들지 않습니다. 각 칸은 타일 인덱스와 뒤집기/회전
플래그를 담은 32비트 타일 ID(GID)입니다.

> **큰 맵 렌더링.** 보이는 청크는 각각 한 번만 그려져 캐시되며, 이동할 때는 다시 그리지 않고
> 캐시된 청크를 재사용하므로 큰 맵을 스크롤해도 부드럽습니다. 새로 보이게 된 영역을 **처음**
> 그리는 작업은 백그라운드(GUI 스레드 밖)에서 미리 준비되어, 따라잡는 동안에도 창이 계속
> 반응합니다.

## Tiled JSON 내보내기 / 가져오기

맵은 **Tiled와 호환되는 JSON**으로 내보낼 수 있고 **손실 없이** 다시 가져올 수 있습니다. 왕복해도
레이어, 모든 칸과 그 뒤집기/회전 플래그, 편집기가 직접 쓰지 않는 필드가 모두 보존됩니다(알 수 없는
필드는 그대로 전달됩니다).

- **내보내기**(**타일맵 ▸ Tiled JSON 내보내기…**)는 올바른 Tiled 맵을 만들며, 레이어 데이터는
  **CSV**로 씁니다.
- **가져오기**(**타일맵 ▸ Tiled JSON 가져오기…**)는 CSV 또는 base64 레이어 데이터(압축 없음,
  gzip, zlib)로 쓰인 Tiled 맵을 읽고, **외부 `.tsj`** 타일셋 참조를 받아들입니다.
- 가져오기는 **방어적으로 검증하며 읽어 들입니다**. 잘못된 형식의 맵, 지원되지 않는
  **zstd** 압축 레이어, 외부 **`.tsx`** 타일셋 참조는 비정상 종료나 조용한 데이터 손상 없이 명확한
  오류와 함께 거부됩니다.

> **왕복 충실도.** 알 수 없는 필드가 왕복 후에도 남고 뒤집기/회전 플래그가 비트 단위로
> 보존되므로, PixelArt Creator와 Tiled 사이에서 맵을 옮겨도 상대 도구가 추가한 데이터를 잃지
> 않습니다.

## 저장과 다시 열기

타일셋과 타일맵은 `.pixproj`에 저장되었다가 그대로 복원됩니다. 프로젝트를 저장했다가 다시 열면
모든 타일셋(원본과 자르기 설정)과 모든 타일맵(레이어, 칸, 칸별 뒤집기/회전 플래그)이 똑같이
복원됩니다. 타일맵이 생기기 전 이전 버전에서 저장한 프로젝트도 계속 열리며, 이 경우 타일셋과
타일맵 없이 불러와집니다.

## 실행 취소, 다시 실행, 그리고 실행 취소할 수 *없는* 것

- **실행 취소 가능(각각 한 단계):** 칸에 스탬프 / 지우기, 영역 사각형 채우기(자동 타일 이웃 다시 계산 포함),
  그리고 타일맵 레이어 추가 / 제거 / 순서 변경 / 표시 전환.
- **실행 취소 불가(보기 상태):** 타일셋 편집기 패널에서 타일 선택, 자동 타일 전환, 다음 스탬프의
  뒤집기 / 회전 선택, 맵 화면 이동.

## 다루지 않는 내용

- 가져올 때 **zstd 압축** Tiled 레이어 데이터와 **외부 `.tsx`** 타일셋은 설계상 거부됩니다
  (가져오기는 CSV와 base64(압축 없음, gzip, zlib), 외부 `.tsj`를 받아들입니다). 지원되는 인코딩 중 하나를
  사용하세요.
- Blob-47 8방향 이웃 방식 외의 **모서리 / 가장자리 Wang** 타일 세트 — 자동 타일은 이후 단계에서
  이를 지원하도록 확장할 수 있게 설계되어 있습니다.
- **애니메이션 타일**과 **오브젝트 레이어** — 이후 단계에서 다룹니다. 이번 릴리스는 타일
  레이어를 다룹니다.
