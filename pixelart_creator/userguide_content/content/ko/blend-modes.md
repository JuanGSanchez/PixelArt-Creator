# 혼합 모드

각 레이어(와 그룹)는 [레이어 패널](layers.md)의 레이어별 드롭다운에서 고른 **혼합 모드**로
합성됩니다. PixelArt Creator는 **열두 가지** 모드를 제공합니다. **표준**과, W3C *Compositing
and Blending Level 1* 사양의 **분리 가능** 모드 중 표준을 뺀 열한 가지입니다(Photoshop / Krita /
SVG와 같은 구성이며 결과도 같습니다).

혼합은 정규화된 부동 소수점 작업 공간에서 **스트레이트(비사전곱) 알파**로 이루어진 뒤 8비트
RGBA로 다시 기록됩니다. **표준**은 스트레이트 알파 source-over 합성입니다.

## 열두 가지 모드

| 모드 | 효과 |
| --- | --- |
| **표준** | 스트레이트 알파 source-over. 완전히 불투명한 레이어는 아래에 있는 것을 대체하고, 완전히 투명한 레이어는 아래를 그대로 둡니다. |
| **곱하기** | 레이어를 아래에 있는 것과 곱합니다. 항상 어두워집니다. 흰색은 중립이며 검은색은 검은색이 됩니다. |
| **스크린** | 곱하기의 반대로, 항상 밝아집니다. 검은색은 중립이며 흰색은 흰색이 됩니다. |
| **오버레이** | 어두운 톤에서는 곱하기, 밝은 톤에서는 스크린으로 동작하여 (아래에 있는 것을 기준으로) 대비를 높입니다. |
| **어둡게** | 두 채널 값 중 더 어두운 쪽을 유지합니다. |
| **밝게** | 두 채널 값 중 더 밝은 쪽을 유지합니다. |
| **색상 닷지** | 레이어를 반영하도록 아래에 있는 것을 밝게 합니다. 강하게 밝아집니다. |
| **색상 번** | 레이어를 반영하도록 아래에 있는 것을 어둡게 합니다. 강하게 어두워집니다. |
| **하드 라이트** | 레이어와 배경의 역할을 바꾼 오버레이로, 거친 스포트라이트입니다. |
| **소프트 라이트** | 더 부드러운 하드 라이트로, 레이어 값에 따라 부드러운 닷지/번이 됩니다. |
| **차이** | 두 값의 절대 차이입니다. 같은 색상은 상쇄되어 검은색이 됩니다. |
| **제외** | 차이와 비슷하지만 중간 톤에서 대비가 더 낮습니다. |

> **불투명도와 혼합 모드는 함께 적용됩니다.** 레이어의 불투명도는 표준뿐 아니라 **모든** 혼합
> 모드에서 레이어의 기여도를 조절합니다. 숨겨진 레이어는 모드와 관계없이 아무것도 더하지
> 않습니다.

## 스택이 합성되는 방식

레이어는 누적되는 결과 위에 **아래에서 위로** 합성됩니다. 보이는 각 레이어의 픽셀은 해당 레이어의
혼합 모드와 불투명도(마스크가 있으면 마스크도)를 사용하여 아래에 있는 것 위에 섞입니다. 표준
레이어만 쌓인 스택은 아래에서 위로 스트레이트 알파 source-over 합성을 차례로 적용해 나가는 것과
정확히 같습니다. 합성은 원본 레이어 버퍼를 절대 바꾸지 않으므로 비파괴적입니다.

편집 한 번은 **영향받는 영역**만 다시 합성하므로, 큰 캔버스에서도 그리기가 빠르게 반응합니다.

## 성능

8K 캔버스(7680 × 4320)에서 픽셀 하나를 그리면 변경된 작은 영역이 약 **1 ms** 안에 다시
합성되며, 16 ms / 60 fps 프레임 예산에 충분히 들어갑니다. 낮은 확대/축소에서 불투명도 슬라이더를
끌거나 여러 레이어에 걸쳐 큰 뷰포트를 다시 그리는 속성 변경처럼 더 무거운 일부 상호 작용은
현재 CPU에 묶여 있어 예산을 넘을 수 있습니다. GPU 셰이더를 이용한 완전한 합성은 이후 개선
사항으로 계획되어 있습니다.

## 관련 주제

- 레이어의 혼합 모드와 불투명도는 [레이어 패널](layers.md)에서 설정합니다.
