# 애니메이션 타임라인

**애니메이션 시스템**은 문서의 프레임 목록을 *타임라인*으로 바꿉니다. 프레임을 추가, 제거,
순서 변경, 복제할 수 있고, 프레임마다 화면에 표시되는 시간을 따로 정할 수 있으며, 네 가지 모드
중 하나로 순서대로 재생할 수 있습니다. 어니언 스킨으로 앞뒤 프레임을 함께 볼 수 있고, 프레임
범위를 프레임 태그로 묶어 **이름이 지정된 애니메이션**으로 만들 수도 있습니다. 프레임과 태그를
편집하는 작업은 모두 실행 취소 한 단계입니다.

타임라인, 재생, 어니언 스킨, 태그에서 **Aseprite**와 같은 수준의 기능을 갖추었으며, 프레임 태그로
**한 파일에 서로 독립적인 이름 있는 애니메이션을 여러 개**(걷기, 달리기, 대기) 둘 수 있다는 점에서
한 걸음 더 나아갑니다.

> **프레임별 독립 레이어.** 각 프레임은 **자기만의** 레이어 스택을 가지며, [레이어 엔진](layers.md)과
> 같은 방식으로 합성됩니다(표시, 불투명도, 혼합 모드, 그룹, 마스크가 모두 프레임별로 적용됩니다).
> **인덱스** 문서에서는 프레임이 인덱스 레이어 하나이며, 합성기가 RGBA 전용이므로 어니언 스킨은
> 표시되지 않습니다.

## 프레임 스트립

**타임라인** 패널은 문서를 재생 순서대로(왼쪽에서 오른쪽으로) 나열한 가로 프레임 스트립으로
보여 줍니다. 각 칸에는 미리 보기 이미지, 프레임 번호, 그 프레임에 걸친 태그 표시가 나타납니다.
레이어 패널에는 현재 활성 프레임의 레이어가 표시됩니다.

- **프레임 선택** — 프레임을 누르거나 방향 키를 사용합니다. 캔버스에는 그 프레임의 합성된 레이어
  스택이 표시됩니다. 선택은 보기 동작이므로 실행 취소할 수 **없습니다**.
- **스크럽** — 스트립을 따라 누른 채 끌면, 캔버스에 커서 아래의 프레임이 계속 표시됩니다. 스크럽도
  실행 취소할 수 **없습니다**.

## 프레임 관리

타임라인 도구 모음에서 프레임 순서를 편집합니다. 각 작업은 **정확히 실행 취소 한 단계**입니다.

| 작업 | 설명 |
| --- | --- |
| **프레임 추가** | 활성 프레임 뒤에 빈 레이어로 이루어진 새 프레임을 삽입합니다. |
| **프레임 제거** | 활성 프레임을 삭제합니다. **프레임이 하나만 남으면 사용할 수 없습니다.** 문서에는 항상 프레임이 하나 이상 있어야 합니다. |
| **프레임 복제** | 원본 뒤에 **독립적인 완전한 사본**(레이어와 지속 시간 포함)을 삽입합니다. 사본을 편집해도 원본은 바뀌지 않습니다. |
| **프레임 끌기** | 칸을 새 위치로 끌어 **순서를 바꿉니다**. 재생과 스크럽은 새 순서를 따릅니다. |

실행 취소하면 내용, 순서, 지속 시간까지 이전 상태가 정확히 복원됩니다.

## 프레임별 지속 시간

프레임마다 밀리초 단위의 **지속 시간**이 있으며, 스트립의 지속 시간 편집기에 표시됩니다(새
프레임은 기본 프레임 지속 시간으로 시작합니다). 새 값을 입력하고 확정하면(Enter 키 또는 포커스
해제) 그 프레임이 머무는 시간이 실행 취소 한 단계로 설정됩니다. 지속 시간은 **양수**여야 하며,
0 이하의 값은 거부됩니다. 재생할 때 500 ms 프레임은 100 ms 프레임보다 약 다섯 배 오래 머뭅니다.

> **균일한 프레임 속도.** 균일한 FPS는 모든 프레임에 같은 지속 시간을 지정한 것과 같습니다
> (`duration_ms = round(1000 / fps)`). 재생 타이밍의 유일한 기준은 언제나 프레임별 밀리초입니다.

## 재생

**재생 컨트롤**이 표시되는 프레임을 시간에 따라 바꿉니다.

- **재생**은 문서 전체를 재생합니다(일시 중지했다면 이어서 재생합니다).
- **일시 중지**는 현재 프레임에서 멈춥니다.
- **중지**는 멈추고, 재생을 누를 때 활성이던 프레임으로 돌아갑니다.
- **Space** 키로 재생과 일시 중지를 전환합니다.

**모드 선택기**는 순서가 진행되는 방식을 정합니다(기본값은 **반복**).

| 모드 | 4프레임 범위에서의 동작 |
| --- | --- |
| **반복** | `0,1,2,3,0,1,2,3,…` — 끝없이 처음으로 돌아갑니다. |
| **한 번** | `0,1,2,3` 후 마지막 프레임에서 **멈춥니다**. |
| **역방향** | `3,2,1,0,3,2,1,0,…` — 거꾸로 돌아갑니다. |
| **핑퐁** | `0,1,2,3,2,1,0,1,2,3,…` — 왕복하며, **양 끝 프레임은 두 번 나오지 않습니다**. |

재생은 각 프레임의 지속 시간을 따르므로, 지속 시간을 바꾸면 다음 재생부터 그 프레임이 화면에
머무는 시간이 달라집니다.

> **큰 애니메이션은 처음 재생할 때 메인 스레드 밖에서 준비합니다.** 여러 레이어로 된 큰(예: 8K)
> 문서의 범위를 처음 재생할 때는 각 프레임의 평탄화된 합성 결과를 한 번씩 만들어야 합니다. 이 작업은
> **GUI 스레드 밖**에서 진행되며, 상태 표시줄에 **취소할 수 있는** 작은 진행률 표시가 나타납니다.
> 창은 계속 반응하고, 재생은 멈추지 않고 프레임이 준비되는 대로 **이어서** 표시됩니다. 준비된
> 프레임은 캐시되므로 다시 재생하거나 스크럽할 때는 60 fps로 동작합니다.

## 어니언 스킨

어니언 스킨은 편집 중인 프레임 아래에 **앞뒤 프레임**을 흐리게 겹쳐 보여 주어 움직임을 맞출 수 있게 합니다.

- 어니언 스킨 전환 버튼으로 **켭니다**. 흐리게 표시되는 프레임은 활성 프레임 아래에 그려지며, 활성
  프레임 자체는 바뀌지 않습니다.
- **이전** 프레임과 **다음** 프레임을 각각 몇 개씩 표시할지 정합니다(`0`이면 그쪽은 꺼집니다.
  기본값은 **이전 1개 / 다음 1개**입니다).
- 각 방향의 **틴트**를 정합니다. 기본값은 이전 프레임이 **빨간색**, 다음 프레임이 **파란색**입니다.
  멀리 있는 프레임일수록 흐려집니다.

어니언 개수와 틴트는 **보기 설정**이므로, 바꾸면 오버레이가 바로 갱신되고 실행 취소 단계는 **생기지
않습니다**. 어니언 스킨은 **재생 중에는 표시되지 않으며**(편집 보조 기능이지 미리 보기가 아닙니다)
스크럽 중에도 표시되지 않습니다.

## 프레임 태그(이름이 지정된 애니메이션)

**프레임 태그**는 프레임 범위에 이름을 붙여 독립된 애니메이션으로 만듭니다. 한 파일에 태그를 여러
개 둘 수 있으며(예: 프레임 1–4에 `walk`, 프레임 0에 `idle`) 서로 겹쳐도 됩니다.

**프레임 태그** 패널에서 다음을 할 수 있습니다.

- 태그 **추가 / 편집 / 삭제** — 각각 대화 상자가 열립니다. 여기서 태그의 **이름**, 양 끝을 포함하는
  **시작 / 끝** 범위, **재생 모드**, **반복** 횟수(반복 계열 모드에서 `0`은 무한), **색상**을
  정합니다. 변경은 각각 **실행 취소 한 단계**입니다. 태그는 해당 프레임에 걸친 구간으로 표시됩니다.
- **태그 재생**은 선택한 태그를 별도의 이름 있는 애니메이션으로 재생합니다. 전체 재생 모드와
  상관없이 **태그 자신의** 재생 모드와 반복 설정에 따라 태그의 범위를 실행합니다. 반복이 3인
  **한 번** 태그는 범위를 세 번 재생한 뒤 멈춥니다.

프레임을 추가하거나 제거하면 태그 범위는 자동으로 올바르게 유지됩니다(새 프레임 수 안으로
맞춰집니다). 실행 취소하면 프레임 변경과 원래의 태그 범위가 함께 복원됩니다.

## 격자 보기(셀 격자)

타임라인 도구 모음의 **격자 보기** 전환 버튼을 누르면 가로 프레임 스트립이 **셀 격자**로 바뀝니다.
프레임이 열, 레이어 트랙이 행이 되는 Aseprite의 셀 격자와 같은 방식입니다. 스트립과 같은 문서를
보여 주므로 이리저리 전환해도 보던 위치를 잃지 않습니다.

- **셀 이동 / 복사** — 셀이 있는 칸을 끌어 다른 프레임/트랙으로 옮깁니다. 끌 때 **Ctrl** 키를 누르고
  있으면 원본을 그대로 두고 복사합니다. 둘 다 실행 취소 한 단계입니다. 이것은 캔버스에서의
  **Ctrl+drag**와는 **다른** 동작입니다. 캔버스에서는 여전히 플로팅 선택 영역을 복사합니다
  ([선택과 플로팅 이동/복사](selection-and-transform.md#copy-instead-of-move-hold-ctrl) 참고). 수정
  키는 같지만, 어느 쪽이 적용되는지는 끄는 위치에 따라 달라집니다.
- **덮어쓰기 확인** — 이미 셀이 있는 칸에 놓으면 **기존 셀을 덮어쓰시겠습니까?** 대화 상자가
  열립니다. **"이 프로젝트에서는 다시 묻지 않음"** 확인란을 선택하면 이 프로젝트에서는 더 이상
  묻지 않습니다. 이 확인을 다시 켜는 방법은 아래의 [프로젝트 확인 창](#project-confirmations)을
  참고하세요.
- **셀별 표시 전환** — 셀의 표시 아이콘을 눌러 그 프레임의 레이어를 표시하거나 숨깁니다. 다른 곳의
  표시 전환과 마찬가지로 실행 취소 한 단계입니다.
- **여기에 셀 만들기** — 빈 칸을 오른쪽 버튼으로 누르거나 키보드의 컨텍스트 메뉴 키를
  누르면 **"여기에 셀 만들기"** 동작이 나타납니다. 이미 셀이 있는 칸이거나 프레임이 최대
  레이어 수에 이미 도달한 경우에는 이 동작이 아예 나타나지 않습니다. 메뉴에는 거부될 동작이
  나타나지 않습니다.
- **스크럽** — 빈 격자 칸을 가로질러 끌면 표시되는 프레임을 스크럽할 수 있으며, 스트립을 따라 끄는 것과
  똑같이 동작합니다.
- **열 순서 변경** — 열 머리글을 끌어 프레임 순서를 바꿉니다. 스트립의 칸을 끄는 것에 해당하는
  격자의 동작입니다.

### 프로젝트 확인 창

격자 보기의 덮어쓰기 확인은 앱의 프로젝트별 환경설정 중 하나입니다. "이 프로젝트에서는 다시 묻지
않음"으로 한 번 끄면 그 프로젝트에서는 꺼진 상태로 유지되며, **편집 -> 프로젝트 확인 창**에서
되돌릴 수 있습니다. 이 메뉴에는 꺼 둔 확인이 모두 나열되고 각각 개별로 다시 켤 수 있습니다.

## 포인터 제스처

프레임 스트립은 위의 [프레임 관리](#managing-frames)에 있는 도구 모음 버튼 외에도 **Ctrl** 키와
함께 쓰는 네 가지 포인터 제스처에 반응합니다.

| 제스처 | 결과 |
| --- | --- |
| **Ctrl+wheel** | 활성 문서를 다음 / 이전 프레임으로 이동합니다. |
| **Ctrl+middle-click** | 활성 문서의 프레임 1로 바로 이동합니다. |
| **Ctrl+left-click** | 활성 프레임 뒤에 프레임을 추가합니다. **프레임 추가** 버튼과 같은 실행 취소 가능한 동작입니다. |
| **Ctrl+right-click** | 활성 프레임을 제거합니다. **프레임 제거** 버튼과 같은 실행 취소 가능한 동작이며, **타임라인 전용**입니다. 격자 보기에는 이에 해당하는 동작이 없습니다. 버튼과 마찬가지로 문서의 마지막 남은 프레임에서는 거부되며, 문서에는 항상 프레임이 하나 이상 있어야 합니다. |

## 저장과 다시 열기

프레임, 프레임별 지속 시간, 프레임 태그는 모두 `.pixproj`에 저장되었다가 그대로 복원됩니다.
태그가 있는 애니메이션을 저장했다가 다시 열면 프레임 순서, 모든 프레임의 지속 시간, 전체 태그
모음이 똑같이 복원됩니다. 태그가 생기기 전 이전 버전에서 저장한 프로젝트도 계속 열리며, 이 경우
태그 모음이 빈 상태로 불러와집니다.

## 실행 취소, 다시 실행, 그리고 실행 취소할 수 *없는* 것

- **실행 취소 가능(각각 한 단계):** 프레임 추가 / 제거 / 순서 변경 / 복제, 프레임 지속 시간 설정,
  태그 만들기 / 편집 / 삭제, 그리고 격자 보기에서의 셀 이동 / 복사, 셀 표시 전환, 셀 만들기.
- **실행 취소 불가(보기 상태):** 프레임 선택과 스크럽, 재생 / 일시 중지 / 중지, 어니언 스킨 개수와
  틴트 변경, 스트립과 격자 보기 사이의 전환.
