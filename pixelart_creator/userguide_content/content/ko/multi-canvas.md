# 여러 캔버스(아트보드)

문서/아트보드 여러 개를 동시에 열 수 있으며, 각각 자기만의 **탭**에 표시됩니다.

## 격리된 탭

열려 있는 캔버스는 각각 완전히 **상태가 격리**되어 있습니다. 탭 하나가 다음을 각자 가집니다.

- 레이어 트리(레이어, 그룹, 마스크, 참조/스마트 레이어)
- 팔레트와 색상 모드
- 실행 취소/다시 실행 내역
- 합성된 보기와 캔버스 형상

탭으로 전환하면 그 캔버스가 활성 컨텍스트가 됩니다. 그 탭의 레이어 트리, 팔레트, 실행 취소
스택, 합성 결과가 현재 상태가 되고 레이어 패널도 그에 맞게 다시 채워집니다.

탭이 격리되어 있으므로 한 캔버스에서 한 작업은 다른 캔버스에 **절대** 영향을 주지 않습니다.
탭 A에서 그리기, 레이어 속성 변경, 순서 변경, 그룹화, 실행 취소를 해도 탭 B의 트리, 합성 결과,
실행 취소 내역은 그대로입니다.

## 아트보드 간 작업

- 아트보드마다 캔버스 크기, 팔레트, 색상 모드가 다를 수 있습니다.
- 실행 취소는 탭마다 따로입니다. 실행 취소해도 다른 아트보드에는 영향이 없습니다.
- 문서를 저장하면 그 탭 자체의 레이어 트리가 `.pixproj` 파일에 기록됩니다.

> **팁.** 같은 스프라이트의 변형본(예: 색상 교체나 포즈)에는 별도의 아트보드를 사용하면 편집 내역이
> 서로 독립적으로 유지됩니다.

## 여러 *캔버스*와 여러 *보기*

여러 캔버스는 격리된 탭이며, 각각 *서로 다른* 문서입니다. 이는 **하나의** 공유 문서에 대해 서로
동기화되는 창을 여러 개 여는 **다중 보기**와 다릅니다. 다중 보기 편집은
[시각 보조와 UX](visual-aids.md)를 참고하세요.
