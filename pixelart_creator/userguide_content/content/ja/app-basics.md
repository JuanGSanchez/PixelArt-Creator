# はじめにとワークスペース

![PixelArt Creator](pac-logo.png)

**PixelArt Creator** へようこそ。PixelArt Creator は、8K キャンバス、非破壊のレイヤーシステム、
アニメーションのタイムライン、タイルセット / タイルマップエディター、エクスポートパイプライン、
自動化とスクリプト、表示補助、クラウドと共同作業のツールを備えた、デスクトップ向けのピクセルアートスタジオです。
このトピックではワークスペースの全体像を紹介し、
ガイドの残りの部分を理解しやすくします。

## メインウィンドウの概要

- **メニューバー** (上部) — あらゆるコマンドへの入り口です。コマンドは
  **ファイル**、**編集**、**表示**、**クラウド**、**ヘルプ**などのメニューにまとめられています。
  いまお読みのアプリ内ユーザーガイドは、
  **ヘルプ ▸ ユーザーガイド**から、または **F1** キーを押して開きます。
- **キャンバス** (中央) — 描画する面です。
  [キャンバス: ズーム、パン、グリッド](canvas-and-view.md)を参照してください。
- **ドック / パネル** (左右) — レイヤーパネル、アニメーションのタイムライン、タイルセットエディターパネル、
  クラウド / 共同作業のパネルがあります。
  ほとんどのパネルは表示と非表示を切り替えられ、作業の進め方に合わせて配置できます。
- **ステータスバー** (下部) — バックグラウンド処理 (エクスポート、再生の準備、クラウドへの保存) の
  進行状況、短い通知が表示されます。

## ドキュメントとタブ

開いている作品はそれぞれ**ドキュメント**で、専用の**タブ**に表示されます。
ドキュメントには、サイズ、カラーモード (**RGBA** または**インデックスカラー**)、パレット、レイヤーツリーがあり、
アニメーションさせる場合はフレームの一覧も加わります。
複数のドキュメントを同時に開いておけます。
[複数のキャンバス (アートボード)](multi-canvas.md)を参照してください。
ドキュメントは **`.pixproj`** プロジェクトファイルとして保存されます。これは検証済みで、バージョン番号付きの保存形式で、
アプリ全体 (クラウド層を含む) がこの形式を使います。

## 元に戻す / やり直す

ペイント、レイヤーの変更、変形、フレームの編集、自動化の実行など、ほとんどすべての編集は、
ドキュメントの**元に戻すスタック**に**ちょうど 1 ステップ**として積まれます。
**元に戻す**は直前のステップを取り消し、**やり直す**はそれを再び適用します。
元に戻す履歴は**タブごと**なので、あるドキュメントで元に戻しても別のドキュメントには及びません。
一部の操作は、編集ではなく表示の状態にあたるため、意図的に元に戻せません。
フレームの選択やスクラブ、オニオンスキンの切り替え、ガイドの追加、
クラウド / 共同作業パネルを開く操作がこれにあたります。

## テーマ (スタイル、ライト、ダーク)

アプリケーションの外観に関する設定はすべて**テーマ**メニューにあります。
どの選択もすぐに反映され、次回アプリケーションを起動したときにも保持されます。

- **スタイル** — 3 つのビジュアルスタイルを選べるサブメニューです。**Washi & Kintsugi** (既定)、
  **Edo Night**、**Arcade Kikko** があり、
  それぞれパネル、ダイアログ、枠線、ウィンドウの模様部分まで統一された、完結した外観です。
- **ライト** / **ダーク** — スタイルとは別に選ぶカラーモードです。すべてのパネル、ダイアログ、
  オーバーレイとこのユーザーガイドは、どちらでも正しく表示され、読みやすさも保たれます。
  色は役割ごとに 1 度だけ定義されるので、テーマはどこでも一貫しています。
- **システムフォントを使用** — インターフェイスの表示を、同梱のピクセル書体 (Nifen
  Art) からオペレーティングシステムのインターフェイス用フォントに切り替えます。
- **ピクセルパーフェクトインターフェイス** — 既定でオンです。インターフェイスを整数倍でのみ拡大縮小するので、
  倍率が整数でないディスプレイ (たとえば 125% や 150%) でもピクセルアートがくっきり表示されます。
  変更は次回アプリケーションを起動したときに反映されます。

## バージョンと情報

ウィンドウのタイトルには常に **PixelArt Creator** に続いて実行中のバージョン、
つまりお使いのビルドの正確な番号が表示されるので、
確認のための手間は要りません。
詳しい情報は**ヘルプ ▸ PixelArt Creator について**を選んでください
(macOS ではアプリケーションメニューの**終了**の隣にあります。この項目はプラットフォームがそこに置きます)。
「PixelArt Creator について」ダイアログには、アプリ名、バージョン (手作業でコピーできるよう選択可能)、ライセンス、
ソースリポジトリ、ドキュメントサイト、リリースページへのリンク、そして
**コピー**ボタンが表示されます。
**コピー**ボタンは、バージョンとあわせてオペレーティングシステム、Python、Qt/PySide6 のバージョンを
1 行にしてクリップボードに入れるので、
そのままバグ報告に貼り付けられます。

## 言語

インターフェイスはすべて翻訳できます。使用言語を切り替えると、すべてのメニュー、
ラベル、メッセージがその場で翻訳され直すので、再起動は要りません。このユーザーガイドの
枠組み (タイトル、セクションのラベル、検索ボックス、ナビゲーション) も使用言語に従います。
ガイドの内容は、その言語の版が同梱されていればその言語で表示され、
なければ既定 (英語) のテキストに戻ります。

## キーボードショートカット

これはアプリケーションのキーボードショートカットの完全な一覧です。ツールのキーすべて、2 つの切り替え、
選択範囲を消去する 2 通りの方法、そしてファイル / 編集 / ヘルプの主な操作を含みます。
キーボードショートカットに触れるこのガイドの他のページは、
ここに繰り返し書かず、この表にリンクしています。

| ショートカット | 操作 |
| --- | --- |
| **A** | 鉛筆ツール — フリーハンドでピクセルを描画します。 |
| **Shift+A** | スポイトツール — キャンバスから色を拾います。 |
| **Q** | 消しゴムツール。 |
| **S** | 長方形ツール。 |
| **W** | 直線ツール。 |
| **Shift+W** | 楕円ツール。 |
| **D** | 矩形選択ツール。 |
| **F** | バケツツール。 |
| **Shift+F** | ディザツール。 |
| **E** | 投げ縄選択ツール (フリーハンド)。 |
| **Shift+E** | 自動選択ツール (連続した同色の範囲)。 |
| **Shift+S** | 長方形ツールと楕円ツールで共通の**塗りつぶし図形**を切り替えます。 |
| **Shift+R** | 開いているすべてのタブのキャンバスビューで**ピクセルパーフェクト**を切り替えます。 |
| **Shift+Q** | 選択範囲の内容を消去します。 |
| **Delete** | 選択範囲の内容を消去します (同じ操作の 2 つ目のショートカット)。 |
| **Ctrl+N** | 新しいドキュメント。 |
| **Ctrl+O** | 既存のプロジェクトを開きます。 |
| **Ctrl+S** | アクティブなプロジェクトを保存します。 |
| **Ctrl+Z** | 直前の元に戻せる操作を取り消します。 |
| **Ctrl+Y** | 直前に取り消した操作をやり直します。 |
| **F1** | このユーザーガイドを開きます。 |

上の 11 個のツールのキーは、描画中に手がタイピングの位置から離れずに済むよう、
ホームポジションとその周辺に意図的に配置されています。**Shift+Q** と
**Delete** は同じこと、つまり選択範囲の内容の消去を行うので、
手がすでに近くにあるほうを使えます。

いくつかのショートカットは、機能を理解してから使うものなので、該当するページに載せています。
**Ctrl+Shift+E** はエクスポートを開きます。
[エクスポートとパイプライン連携](export-and-pipeline.md)を参照してください。**Ctrl++** / **Ctrl+-** は
キャンバスをズームします。ホイールや中ボタンクリックでパン、ズーム、色の取得を行うポインター操作は
[キャンバス](canvas-and-view.md)を参照してください。**Ctrl+A** /
**Ctrl+I** / **Ctrl+Shift+A** / **Shift+H** / **Shift+V** と選択範囲のドラッグ操作は
[選択とフローティング移動 / コピー](selection-and-transform.md)を参照してください。
タイムライン上の **Ctrl+wheel**、**Ctrl+middle-click**、**Ctrl+left-click**、
**Ctrl+right-click** は[アニメーションのタイムライン](animation-timeline.md)を参照してください。
**Space** キーはアニメーションの再生 / 一時停止を切り替えますが、メニューのショートカットではまったくなく、
フレームが 2 つ以上あるドキュメントを開いているときにしか働きません。**Esc** キーは
進行中の操作 (多くはフローティング選択範囲の移動) をキャンセルし、**Enter** キーは確定します。
その対象の詳細は
[選択とフローティング移動 / コピー](selection-and-transform.md)を参照してください。
