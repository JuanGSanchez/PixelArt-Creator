# ブレンドモード

各レイヤー (とグループ) は、[レイヤーパネル](layers.md)のレイヤーごとのドロップダウンで選んだ**ブレンドモード**で合成されます。
PixelArt Creator には **12 種類**のモード、つまり**通常**と、W3C の *Compositing and
Blending Level 1* 仕様にある 11 種類の通常以外の**分離可能**なモードが用意されています (Photoshop / Krita / SVG と同じ顔ぶれで、同じ結果になります)。

ブレンドは、正規化された浮動小数点の作業空間で**ストレート (乗算済みでない) アルファ**を使って行われ、
その後 8 ビットの RGBA に書き戻されます。**通常**は、ストレートアルファによる source-over 合成です。

## 12 種類のモード

| モード | 効果 |
| --- | --- |
| **通常** | ストレートアルファの source-over です。完全に不透明なレイヤーは下の内容を置き換え、完全に透明なレイヤーは下の内容を変えません。 |
| **乗算** | レイヤーと下の内容を掛け合わせます。常に暗くなります。白は影響せず、黒は黒になります。 |
| **スクリーン** | 乗算の逆です。常に明るくなります。黒は影響せず、白は白になります。 |
| **オーバーレイ** | 暗い色調では乗算、明るい色調ではスクリーンになり、(下の内容を基準に) コントラストが強まります。 |
| **比較（暗）** | 2 つのチャンネル値のうち暗いほうを残します。 |
| **比較（明）** | 2 つのチャンネル値のうち明るいほうを残します。 |
| **覆い焼きカラー** | レイヤーを反映するように下の内容を明るくします。強く明るくなります。 |
| **焼き込みカラー** | レイヤーを反映するように下の内容を暗くします。強く暗くなります。 |
| **ハードライト** | オーバーレイでレイヤーと背面の役割を入れ替えたもので、きついスポットライトのようになります。 |
| **ソフトライト** | より穏やかなハードライトで、レイヤーの値に応じて柔らかい覆い焼き / 焼き込みになります。 |
| **差** | 2 つの値の差の絶対値です。同じ色どうしは打ち消し合って黒になります。 |
| **除外** | 差に似ていますが、中間調のコントラストが低くなります。 |

> **不透明度とブレンドモードは組み合わさります**。レイヤーの不透明度は、通常だけでなく**すべての**ブレンドモードで
> そのレイヤーの寄与を調整します。非表示のレイヤーは、モードにかかわらず何も寄与しません。

## スタックの合成方法

レイヤーは、途中の結果の上に**下から上へ**合成されます。表示されている各レイヤーのピクセルは、
そのレイヤーのブレンドモードと不透明度 (マスクがあればマスクも) を使って、下の内容の上にブレンドされます。
通常レイヤーだけのスタックは、下からストレートアルファの
source-over を順に重ねていくのとまったく同じです。合成によってソースのレイヤーバッファーが変更されることはありません。非破壊です。

1 回の編集で再合成されるのは**影響を受ける領域**だけなので、
大きなキャンバスへの描画も軽快なままです。

## パフォーマンス

8K キャンバス (7680 × 4320) では、1 ピクセルの描画による再合成は、更新が必要な小さな領域で
およそ **1 ms** で済み、16 ms / 60 fps のフレーム予算に十分収まります。
低いズームでの一部の重い操作、たとえば不透明度スライダーのドラッグや、
多数のレイヤーにわたって大きなビューポートを再描画する属性の変更は、現状では CPU の処理速度が上限になり、
予算を超えることがあります。GPU シェーダーによる完全な合成は、今後の拡張として計画されています。
