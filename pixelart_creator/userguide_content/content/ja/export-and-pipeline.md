# エクスポートとパイプライン連携

**エクスポートシステム**は、プロジェクトをゲームのパイプラインで使えるアセットに変換します。
出力できるのは、単一の **PNG**、**アニメーション GIF**、**スプライトシート**、詰め込み済みの**テクスチャアトラス**のいずれかで、
それぞれに任意で **Aseprite 形式の JSON** メタデータと、**Unity** や **Godot** にそのまま渡せる**エンジンプリセット**を付けられます。
エクスポートダイアログから 1 つのエクスポート先を書き出すことも、一括エクスポートパネルで複数をまとめて処理することも、
`pixelart-export` コマンドラインから GUI なしで全体を処理することもできます。どの方法でも、出力は**まったく同じバイト列**になります。
エクスポートダイアログは、**ファイル ▸ エクスポート…** または **Ctrl+Shift+E** で開きます。

> **バイト単位で再現できるエクスポート**。エクスポートは**常に同じ結果**になります。入力のドキュメントとパラメーターが同じなら、
> 出力のバイト列は毎回同一です。フレームは明示した順序で処理され、GIF は固定の共有パレットを使ってディザリングを行わず、
> エンコーダーのバージョンも固定されています。GUI と CLI は**同じ**エンジンで動くので、同じドキュメントを GUI で
> エクスポートした結果と CLI でエクスポートした結果は**バイト単位で同一**です。この保証は
> *同一環境* (固定されたツールチェーン) が前提で、異なるマシン間での同一性は保証されません。

| ショートカット | 操作 |
| --- | --- |
| **Ctrl+Shift+E** | エクスポートダイアログを開きます。 |

## ラスターエクスポート (PNG / GIF)

- **PNG** は、**フレーム 0** を 1 枚の RGBA 画像として書き出します。静止画向けのエクスポート先です。
- **GIF** は、アニメーションを書き出します。すべてのフレームが順番に、それぞれ固有の**フレームごとの表示時間**
  ([アニメーションのタイムライン](animation-timeline.md)で設定した値) で表示され、
  ループ回数、フレームの廃棄方法、透明度がファイルに書き込まれます。すべてのフレームが
  **固定の共有パレット** (アニメーション全体に対するメディアンカット法による減色) を使い、ディザリングは**オフ**です。
  これが GIF のバイト単位での再現性を支えています。

> **GIF のループ回数**。`--loop` フラグ (CLI) と**ループ回数**フィールド (ダイアログ) は、GIF を何回繰り返すかを指定します。
> **`0` は無限にループ**することを意味します。

## スプライトシートとテクスチャアトラス

- **スプライトシート**は、すべてのフレームを**均一なグリッド**の上に、行優先 (左から右、上から下) で並べます。
  フレーム `k` は、列 `k % columns`、行 `k // columns` に配置されます。スプライト間の**パディング**は設定できますが、
  外周の余白はありません。列数を指定すると、シートの形を調整できます。
- **テクスチャアトラス**は、共有の **MaxRects** アルゴリズムでフレームを隙間なく詰め込みます
  (回転はオフなので、スプライトは常に縦横の軸に沿って配置されます)。フレームごとに内容が大きく異なるときは、
  アトラスのほうが省スペースです。

> **アトラスのサイズ上限**。アトラスのサイズは、プラットフォームの **8K** という上限以内に制限されます。
> スプライトの集合がその上限に収まらない場合、エクスポートは**安全に中止され**、明確なアトラスのエラーが表示されます
> (重なりや切り捨てが黙って起きることも、異常終了することもありません)。
> パディング、フレームのサイズ、フレーム数のいずれかを減らして、もう一度試してください。

## JSON メタデータ

スプライトシートとアトラスのエクスポートでは、**Aseprite *Array*** 形式の **JSON メタデータの付属ファイル**を
一緒に書き出せます。内容は、`frames[]` 配列 (各フレームの矩形、元のサイズ、表示時間) と、フレームの**タグ**および
フレームごとの表示時間を持つ `meta{}` ブロックです。この JSON は**常に同じ内容**になります。
キーは並べ替えられ、区切り文字は固定で、座標は整数なので、読み込み直しても同じ内容になり、差分も見やすくなります。
ダイアログでは **JSON メタデータを書き出す**チェックボックスで切り替え、CLI では
`--json` / `--no-json` で指定します (既定ではオンです)。

## エンジンプリセット (Unity / Godot)

画像と JSON に加えて、**エンジン向けにそのまま使えるプリセット**も書き出せるので、アセットをそのままプロジェクトに
ドロップできます。

| プリセット | 書き出される内容 |
| --- | --- |
| **Unity** | スプライトの `.meta` 付属ファイル。スプライトモード **Multiple**、`pixelsPerUnit`、ピボット、`filterMode = Point` (ピクセルがくっきり表示され、バイリニア補間によるぼかしがありません) が設定されます。 |
| **Godot** | `SpriteFrames` の `.tres` リソース (Godot 4.2) で、エクスポートしたフレームから作られます。 |

プリセットはダイアログで選ぶか、CLI で `--preset unity` または `--preset godot` を渡して指定します
(既定の `--preset none` では、プリセットは書き出されません)。プリセットのファイルは、画像と同じレイアウトのメタデータから
常に同じ内容で生成されます。

## 一括エクスポート

**一括エクスポートパネル**では、**複数のエクスポート先をまとめて**キューに入れられます。たとえば 1 つのプロジェクトから、
PNG、GIF、Unity 向けのアトラスを 1 回の実行で書き出せます。一括エクスポートは**失敗しても続行**します。
1 つが失敗しても (たとえばアトラスが収まらない場合)、残りは通常どおり書き出され、失敗はその 1 つについてだけ報告されます。
そのため、問題のある 1 つによって一括処理全体が止まることはありません。

## エクスポートしたファイルをライブラリに登録する

エクスポートダイアログには、**アセットライブラリにも追加**というチェックボックスがあり、エクスポートと同時に、
エクスポートしたファイルを[アセットライブラリ](asset-library.md)に登録できます。既定ではオフで、必要なときだけ使う
オプトイン方式です。チェックを入れると、エクスポートに成功した後で、共通の**アセットを登録**ダイアログ
(名前、種類、タグ) が開きます。チェックを入れないままなら、ライブラリには一切触れずにエクスポートされ、
このオプションができる前とまったく同じです。

## 応答性

エクスポートの作業はすべて、**バックグラウンド処理**で実行され、**キャンセルできる進行状況インジケーター**が表示されるので、
大きなアニメーションやアトラスをエクスポートしてもウィンドウが固まることはありません。
エクスポートはドキュメントに対して**読み取り専用**で、ドキュメントを変更せず、元に戻すスタックにも何も積みません。

> **大きな単体エクスポートのキャンセル**。キャンセルは、エクスポート先の切り替え時には速やかに反映されます。
> **大きな 1 件のエンコード途中**でのキャンセルはすぐには反映されず、実行中のエンコードが終わってから
> キャンセルが認識されます。

## `pixelart-export` コマンドライン

自動化や CI のために、`pixelart-export` は**まったく同じ**エクスポート経路を GUI なしで実行します。
出力は、同じドキュメントとパラメーターでの GUI エクスポートとバイト単位で同一です。
`.pixproj` は、アプリ自身が使うものと同じ、防御的で検証済みのプロジェクトローダーで読み込まれます。

```
pixelart-export --input PROJECT.pixproj --format FORMAT --output OUT [options]
```

| フラグ | 意味 |
| --- | --- |
| `--input PATH` | **(必須)** エクスポートする元の `.pixproj` プロジェクト。 |
| `--format FORMAT` | **(必須)** `png`、`gif`、`sprite-sheet`、`atlas` のいずれか。 |
| `--output PATH` | **(必須)** 出力する画像のパス。 |
| `--preset PRESET` | エンジンプリセット：`none` (既定)、`unity`、`godot`。 |
| `--columns N` | スプライトシートの列数。 |
| `--padding N` | スプライト間のパディング (ピクセル単位)。 |
| `--loop N` | GIF のループ回数 (`0` = 無限にループ)。 |
| `--tag NAME` | 指定した名前のフレームタグの範囲だけをエクスポートします (既定：ドキュメント全体)。 |
| `--json` / `--no-json` | スプライトシート / アトラスの JSON 付属ファイルを書き出す / 書き出さない (既定：書き出す)。 |

**終了コード**：`0` は成功、`1` はエクスポート / パッキング / 書き込みのエラー (たとえば、アトラスが収まらない場合や、
ファイルシステムへの書き込みに失敗した場合)、`2` は引数が正しくない場合、またはプロジェクトが不正または読み取れない場合です。

> **GUI と同じ経路**。CLI とダイアログは同じエンジンを呼び出すので、まず対話的にエクスポートを試し、
> その後、同じパラメーターをフラグとして渡せば、ビルドスクリプトでまったく同じ結果を再現できます。

## 対象外の内容

- **APNG** (アニメーション PNG) は**今後の対応**です。このリリースでは、静止画の PNG (フレーム 0) とアニメーション GIF をエクスポートします。
- **マシンをまたいだバイト単位の同一性** — バイト単位の再現性の保証は、*同一環境* (固定されたツールチェーン) が前提です。
  別のマシンのツールチェーンでは、異なるバイト列になることがあります。
- **大きな 1 件のエンコード途中での細かいキャンセル** — キャンセルが認識されるのはエクスポート先の切り替え時で、
  1 件のエンコードの途中ではありません。
