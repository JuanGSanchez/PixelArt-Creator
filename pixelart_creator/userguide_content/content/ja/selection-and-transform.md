# 選択とフローティング移動 / コピー

領域を選択すると、作品の一部だけを対象に作業できます。さらに**フローティング選択範囲**を使うと、
アクティブな選択範囲の中の色を拾い上げて、**リアルタイムの非破壊プレビュー**として移動、または
コピーできます。フローティング選択範囲の*下*にあるピクセルは、確定するまで
**変更されない**ので、移動は位置を調整し直すのも取りやめるのも常に安全です。

これは Aseprite、Pro Motion NG、Pixelorama、Krita でおなじみの動作、つまり持ち上げ、ドラッグし、置く操作です。

> **アクティブなレイヤーだけが対象です**。フローティングの移動 / コピーは**アクティブなレイヤー**に対して働きます
> ([レイヤーパネル](layers.md)を参照)。インデックスカラーのドキュメントでは、それは唯一のインデックスカラーレイヤーです。
> ほかのレイヤーには手を触れません。

## 選択範囲の作成

作業したい領域は、選択ツールで指定します。

| ツール | 選択されるもの |
| --- | --- |
| **矩形選択** | ドラッグして描く長方形の領域。 |
| **投げ縄選択** | 囲むように手描きした領域。 |
| **自動選択** | クリックした位置の、似た色が連続する範囲。 |

**選択範囲の維持**。上の 3 つの選択ツールのどれかに切り替えると、常に現在の選択範囲が
**破棄**されて新しく始まります。新しい選択範囲が前の選択範囲の形を引き継ぐことはありません。
それ以外のツール (鉛筆、消しゴム、バケツ、…) に切り替えた場合は、
現在の選択範囲が**維持される**ので、マスクで制限した描画が引き続き働き、別のツールで描いても
ストロークは選択範囲の内側に収まります。

上の 3 つの選択ツールのいずれかがアクティブなあいだは、**Shift** キーと **Alt** キーの意味が
キャンバス上のほかの場所とは変わります。下の
[パンと選択範囲の作成の違い](#panning-vs-building-a-selection)を参照してください。

| 修飾キー | 選択ツールがアクティブなときの結果 |
| --- | --- |
| **Shift**+ドラッグ | 現在の選択範囲に**追加**します。 |
| **Alt**+ドラッグ | 現在の選択範囲から**除外**します。 |

### パンと選択範囲の作成の違い

| 操作 | 結果 |
| --- | --- |
| **Shift+left-drag** | キャンバスをパンします。ただし選択ツールがアクティブなときは**例外**で、上の表のとおり、代わりに選択範囲に**追加**します。 |

### キャンバス全体の選択、反転、解除

| ショートカット | 操作 |
| --- | --- |
| **Ctrl+A** | キャンバス全体を選択します。 |
| **Ctrl+I** | 現在の選択範囲を反転します。 |
| **Ctrl+Shift+A** | 選択を解除します (現在の選択範囲をクリアします)。 |

選択範囲の**内容**を消去する操作 (選択範囲そのものではありません) は別のアクションで、
専用のショートカット **Shift+Q** と **Delete** があります。
[アプリケーションの基本](app-basics.md)の表を参照してください。

## 持ち上げと移動 (ドラッグ)

フローティングは、すでにアクティブな選択範囲を持ち上げます。新しい選択範囲の形は**作らず**、
今あるマスクを再利用します。

1. 選択ツール (矩形選択、投げ縄選択、自動選択) のどれかがアクティブな状態で、アクティブな選択範囲の**内側を押します**。マスクされたピクセルが
   フローティングのプレビューとして持ち上がります。
2. **ドラッグします**。フローティングした色がカーソルに付いてきて、元の領域はリアルタイムのプレビューで
   **透明に消去された状態** (インデックスカラーモードではインデックス 0) に見えます。
3. 下のピクセルはまだ**変更されません**。変わるのはプレビューだけです。

アクティブな選択範囲の**外側**を押しても**持ち上がらず**、通常どおり新しい選択範囲が始まります。

## 移動ではなくコピー: Ctrl キーを押したままにする

ドラッグ中に **Ctrl** キーを押したままにすると、フローティングが**コピー**に切り替わります。

- **元の領域はそのまま残り** (何も空にならず)、
- 色の**コピー**がカーソルに付いてきます。

コピーしていることを示すコピーモードのカーソル / 表示が出ます。ドラッグ**中**に Ctrl キーを押したり離したりして、
移動とコピーを切り替えられます。

> **コピーの修飾キーは Ctrl キーだけで、Alt キーではありません**。コピーは **Ctrl キーだけ**です。**Alt キーはコピーの修飾キーではありません**。
> 選択範囲内部での Alt ドラッグは、選択範囲の作成における**除外**の操作で、その意味は変わりません。
> 内部のドラッグで **Ctrl+Alt** を押したままにすると、コピーではなく Alt による除外になります。
> コピーするには **Ctrl** キーだけを使ってください。

| 内部でのドラッグ | 結果 |
| --- | --- |
| *修飾キーなし* | 選択範囲を持ち上げて**移動**します (確定時に元の領域は空になります) |
| **Ctrl** | 選択範囲を**コピー**します (元の領域は残ります) |
| **Alt** | 選択範囲から**除外**します (作成の操作) |
| **Shift** | 選択範囲に**追加**します (作成の操作)。選択ツールがアクティブでないときは、追加ではなく **Shift+left-drag** でパンします。上の[パンと選択範囲の作成の違い](#panning-vs-building-a-selection)を参照してください。 |

## 確定とキャンセル

フローティングは、次のいずれかで**確定**されます。

- マウスボタンを**離す**、
- **Enter / Return** キーを押す、または
- **ツールを切り替える** (またはキャンバスのタブを切り替える)。

確定すると、変更は**元に戻せるちょうど 1 ステップ**として適用されます。

- **移動** — 元の領域は透明に書き込まれ (インデックスカラーモードではインデックス 0)、
  色は移動先にスタンプされます。
- **コピー** — 色は移動先にスタンプされ、元の領域は変更されません。

確定後、選択範囲のマスクは**移動先に追従します**。

**Esc** キーを押すと**キャンセル**されます。フローティングはバッファーに書き込まないため、キャンセルすると
移動前のキャンバスが**そのまま**復元され、元に戻す履歴には**何も記録されません**。選択範囲のマスクは
持ち上げる前の位置に戻ります。

> **ドラッグしないクリックにコストはかかりません**。オフセット 0 での確定 (移動せずに選択範囲の内側をクリックしたとき) は
> 何も行われず、元に戻すステップも作られません。

移動先にすでにピクセルがある場合は、先に**既存のピクセルを上書きしますか?** ダイアログで確認を求められます。
**続行**は通常どおり確定を適用し、**キャンセル**は何も適用せず、
フローティングを現在のオフセットのままアクティブにしておきます。
「このプロジェクトでは今後確認しない」にチェックを入れても、実際に受け入れたときに初めて
抑止が記録されます。チェックを入れてキャンセルした場合は何も記録されません。

## キャンバスの外側の端

フローティングは、キャンバスの**一部または全部を外に出して**ドラッグできます。確定すると、キャンバス外のピクセルは
**破棄され** (折り返されることはありません)、エラーなしで作品を端いっぱいまで寄せられます。
移動では、ドラッグした距離にかかわらず、範囲内にある元の領域がすべて空になります。

## 元に戻す、やり直す、レンダリング

- 確定した移動またはコピーは、元に戻す **1** ステップです。**元に戻す**と移動前のバッファーが
  そのまま復元され、**やり直す**と再び適用されます。
- フローティングのプレビューは、どのズーム倍率でも**ニアレストネイバー**で**アンチエイリアスなし**に描画され、
  **ライト**テーマでも**ダーク**テーマでも読み取りやすい表示です。
- ドラッグ中のプレビューはフローティングが触れる領域だけを更新するので、8K キャンバスでも
  16 ms / 60 fps のフレーム予算に収まります。

## ドキュメント全体の変形

**画像 ▸ 拡大縮小…**、90° の 2 つの回転、2 つの反転は、何も選択していないときは、
すべてのフレームのすべてのレイヤーとマスクを含む**ドキュメント全体**に作用します。
アクティブな選択範囲があるときは、これらの操作はこれまでどおり、
アクティブなレイヤーのマスクされた領域だけを変形します。

| ショートカット | 操作 |
| --- | --- |
| **Shift+H** | 選択範囲 (またはドキュメント全体) を左右反転します。 |
| **Shift+V** | 選択範囲 (またはドキュメント全体) を上下反転します。 |

RotSprite だけは例外で、選択範囲の有無にかかわらず常にアクティブなレイヤーだけを変形します。
その回転はバッファーの寸法を変えず、より広い範囲を必要としたこともないからです。

> **大規模な変形は先に確認します**。リサンプリングした結果と元に戻すために保持するバッファーの合計が
> 506.25 MiB (8K キャンバス 4 枚ぶんの RGBA データ) を超えるときは、何かを実行する前に
> **大規模な変形の確認**ダイアログが、見込まれるメモリ使用量をそのまま示します。
> **キャンセル**が既定のボタンなので、Return キーを押しても変形は開始**されません**。
> 意図して**続行**をクリックする必要があります。
> 取りやめた場合、ドキュメントはまったく変更されず、元に戻すスタックにも何も積まれません。
> このしきい値を下回るときは、ダイアログはまったく表示されません。

ドキュメント全体の変形が実行中のあいだは、**ドキュメントを変形中**の進行状況ダイアログがバッファーごとに進み具合を表示し、
いつでもキャンセルできます。キャンセルボタン、Escape キー、ウィンドウ自体の閉じるボタンのどれでも使えます。
キャンセルは途中経過を残しません。すでに何個のバッファーがリサンプリングされていても、
ドキュメントは元のままで、元に戻すスタックには何も積まれません。

## 対象外の内容

- *フローティング中の*選択範囲の**回転や拡大縮小** — 先に移動を確定してから、
  変形ツールを使ってください。
- **すべてのレイヤーを移動**するバリエーション — フローティングはアクティブなレイヤーだけが対象です。
- フローティングの**ドキュメント間でのドラッグ**、またはフローティングの `.pixproj` への保存 — フローティングは
  一時的な編集状態であり、常に先に確定またはキャンセルされます。
