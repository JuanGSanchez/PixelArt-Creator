# 右クリックのカラーハブ

**カラーハブ**は、**作業している、まさにその場所**で呼び出せるコンテキストメニューです。
キャンバス上で**右クリック**すると、カーソルの位置に開きます。色を選ぶ素早い方法が 2 つあり、
厳選した**お気に入り**の一覧と、リアルタイムの**色彩理論に基づく配色**を備えた
本格的な**カラーホイール**です。選んだ色はすぐに適用されます。

## ハブを開く

[キャンバス](canvas-and-view.md)上の好きな場所で右クリックします。カラーハブはカーソルの位置に表示されるので、
色を変えるために離れた場所のパネルまで移動する必要がありません。色を選ぶとすぐに**アクティブな色**になり、
アクティブなスウォッチもそれに合わせて更新されます。
**ハブが開いているときにもう一度右クリックすると、何も選ばずにハブが閉じる**ので、
いったん戻って、元の場所から描画を続けられます。

## お気に入り

**お気に入り**は、よく使う色を保存した、自分だけの一覧です。

- **お気に入りに追加**は、現在の色を保存し、次回からワンクリックで使えるようにします。
- 不要になった色を**削除**します。
- **上へ移動** / **下へ移動**でお気に入りを並べ替え、よく使う色を先頭に置きます。

お気に入りの一覧はセッションをまたいで**保持される**ので、アプリを開き直しても、作業用のパレットがそのまま残っています。
お気に入りをクリックすると、すぐに適用されます。

ハブを開かずにお気に入りへ届く操作もあります。

| 操作 | 結果 |
| --- | --- |
| **Middle-click** | お気に入りの先頭の項目を選んでアクティブな色にします。ハブが開いていてもいなくても、その場で行われます。 |

## カラーホイール

**カラーホイール**は、Canva 風の RGB ホイールで、色相と彩度で好きな色を選び、
明度 (明るさ) のコントロールも使えます。ホイール上を動かすと、アクティブな色がリアルタイムで更新されます。

## 色彩理論に基づくリアルタイムの配色

ホイール上で色を選んでいる間、ハブは現在の色から標準的な色彩理論で導いた**配色のスウォッチ**を表示するので、
当て推量なしに、まとまりのあるパレットを作れます。

| 配色 | 現在の色との関係 |
| --- | --- |
| **補色** | 反対側の色相 (+180°) です。コントラストが最大になります。 |
| **類似色** | 隣り合う色相 (±30°) です。穏やかでまとまりのある配色になります。 |
| **トライアド** | 120° 離れた 2 つの色相 (±120°) です。バランスがよく鮮やかです。 |
| **テトラッド** | 90° ずつ等間隔に離れた 3 つの色相です。4 色で、コントラストが高くなります。 |
| **スプリット補色** | 補色の両隣にある 2 つの色相 (±150°) です。 |
| **シェード**と**ティント** | **シェード**は現在の色の暗い段階、**ティント**は明るい段階です。**カラーランプ**パネル (**パレット**メニューから開きます) では、現在の色に対するシェード、ティント、トーンのランプ全体を並べて表示でき、それぞれに**パレットに追加**ボタンがあります。 |

ホイール本体と、その周囲に並ぶ小さな円である配色のスウォッチは、
動作が異なります。この 2 つは区別して覚えておくと役立ちます。

- **ホイールのパッドはスウォッチではありません**。ドラッグすると、現在選択されている配色の円の色が設定されます。
  ダブルクリックの動作はありません。
- **配色の円を 1 回クリックすると、その円の色でそのまま描画されます**。円自身の色は変わりません。
  ホイールも円も何も変わらず、変わるのはキャンバスだけです。
- **円をダブルクリックすると、その色を代わりに採用します**。何も描画せずに、
  その色がアクティブな色になります。キーボードでも同じ操作ができます。
  Tab キーで円にフォーカスし、**Space** キーまたは **Enter** キーを押すと採用されます。

つまり、1 回のクリックは、アクティブな色を変えずに配色の色でその場で描画するためのもので、
ダブルクリック (またはフォーカスした円での Space キーまたは Enter キー) は、その色をアクティブな色として
確定するためのものです。配色は、ホイール上を動かすたびにリアルタイムで再計算されます。

## 適用と保存

- **色の選択** — 選んだ色がすぐにアクティブになり、アクティブなスウォッチにも反映されるので、
  次のストロークでその色が使われます。
- **お気に入りに追加** — 気に入った色を後のために残します。

## パレットとインデックスカラーのドキュメント

カラーハブは、ドキュメントの**パレット**と連携して動作します。**インデックスカラー**のドキュメントでは、
パレットは作品で使う色の固定された集合です。`.gpl`、`.hex`、`.pal` ファイルをウィンドウにドロップすると、
パレットを読み込めます
([ドラッグ&ドロップによるインポート](drag-drop-import.md)を参照)。パレットの置き換えは、元に戻せる 1 ステップです。
