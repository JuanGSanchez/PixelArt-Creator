# タイルセット、タイルマップ、オートタイル

**タイルマップシステム**は、元の画像を再利用できる**タイルセット**に変え、そのタイルを使って**複数レイヤーの無限マップ**に
大きなレベルを描けるようにします。画像をインデックス付きのタイルに分割し、
セルにスタンプ / 消去 / 塗りつぶしを行い、**オートタイル**に境界の処理を任せ、配置するときにタイルを
反転や回転させ、マップ全体を Tiled 互換の JSON として**エクスポート / インポート**できます。
マップの編集は、どれも元に戻せる 1 ステップです。

> **論理タイルと表示タイル**。オートタイルは、*配置する*タイル (**論理**タイル) と、*表示される*タイル
> (**表示**タイル) を分けて扱います。「壁」のタイルを 1 つ描くだけで、マップが隣接するタイルから
> 正しい辺 / 角のバリエーションを選びます。保存され、読み込み直しても変わらないのは論理タイルの配置なので、
> 結果は**常に同じになり、元に戻せます**。オートタイルをオフにすると、論理タイルがそのまま表示されます。

## タイルセット

**タイルセット**は、同じ大きさのタイルのグリッドに分割した元の画像です。**タイルセットエディター**パネル (タイルマップメニュー) を開き、
**タイルマップ ▸ 画像から新しいタイルセット…** でタイルセットを追加します。
画像は、指定した**タイルサイズ**、必要に応じて指定する外側の**余白**、タイル間の**間隔**で分割され、
できたタイルに左から右、上から下の順に `0` から番号が付きます。

- 各タイルは元のバッファーの一領域なので、タイルセットは複数のコピーではなく、**1 枚の画像が元になっています**。
- すべてのレイヤーに配置されたそのタイルのすべてのインスタンスに、**元のタイルの編集が反映されます** — タイルを 1 回描き直すだけで、
  レベル全体が更新されます。
- パネルには、分割されたタイルが選択用のグリッドとして表示されます。選択したタイルが、スタンプツールで描かれるタイルです。

> **余白と間隔**。`margin` は画像全体の周囲で読み飛ばす縁で、
> `spacing` はタイルと**タイルの間**で読み飛ばす隙間です。1 px の隙間を空けて書き出したシートでは、通常 `spacing = 1`
> (隙間が端も囲んでいる場合は `margin = 1` も) が必要で、これで分割位置が各タイルにぴったり合います。

## タイルマップへの描画

**タイルマップキャンバス**では、グリッド上のセルに、1 セルにつき 1 つのタイルを描きます。
タイルセットエディターパネルでタイルを選び、次のマップツールを使います。

| ツール | 内容 |
| --- | --- |
| **スタンプツール** | カーソルの下のセルに、選択したタイルを配置します (ドラッグすると連続して描けます)。 |
| **タイル消しゴム** | セルを空の状態に戻します。 |
| **矩形塗りつぶし** | ドラッグして描いた矩形の範囲を、選択したタイルで塗りつぶします。 |

スタンプ / 消去 / 矩形塗りつぶしは、どれも**元に戻せるちょうど 1 ステップ**で、元に戻すと以前のセルが正確に復元されます。
既存のタイルの近くに描くと、**オートタイル**の周辺のセルが再計算されるので、描きながらでも境界が正しく保たれます。

### 反転と回転

スタンプを押す前に、タイルを変形できます。**スタンプを左右反転**と**スタンプを上下反転**はタイルを鏡像にし、**スタンプを 90° 時計回りに回転**は
4 つの直角の向きを順に切り替えます。この変形は、配置したセルごとに、タイルに付く小さなフラグとして
保存されるので、タイルを反転や回転させても**タイルセットの項目は増えず**、
保存して読み込み直しても完全に同じです。変形は決まった順序 (対角、次に水平、次に垂直) で組み合わされるので、
同じ組み合わせは常に同じ見た目で描画されます。

## オートタイル

**オートタイル**は、各セルの*表示*タイルを、**8 つの隣接セル**から決定します (Blob-47 方式：隣接 8 方向の
ビットマスクで、角は両隣の辺が揃っているときだけ有効になり、47 種類のタイルが得られます)。
「地形」のタイルを 1 つ描くだけで、正しい直線の辺、内側の角、外側の角が自動的に補われます。

- タイルマップレイヤーパネルの**オートタイル (Blob-47)** チェックボックスで、オートタイルを**切り替え**ます。**オン**のとき、セルへの描画、消去、矩形塗りつぶしは、
  影響を受けるセルと**隣接セル**も再計算するので、境界が常に一貫した状態になります — すべて同じ 1 回の元に戻すステップの中で
  行われます。
- 表示タイルは、論理タイルの配置と隣接セルだけから**常に一意に決まる**ので、同じマップは必ず同じ表示タイルで描画されます。
- オートタイルを**オフ**にすると、境界の処理は行われず、配置した論理タイルがそのまま表示されます。

## レイヤーと無限マップ

タイルマップは**複数レイヤー**です — 背景、地形、ディテールのレイヤーを重ね、それぞれを独立して描けます。
エディターのほかの部分と同じレイヤーモデル (追加 / 削除 / 並べ替え / 表示 / 非表示) を使います。
**タイルマップレイヤー**パネルでスタックを管理し、表示中のレイヤーは合成されて表示されます。

マップ自体は**無限**です。セルは、**16×16 のチャンクの疎なグリッド**として保存されるので、実際に描いた領域だけが
メモリを使います。マップのサイズをあらかじめ決めなくても、原点から (どの方向にでも) 遠く離れた場所にスタンプでき、
空の領域は何も消費しません。各セルは 32 ビットのタイル ID (GID) で、タイルの番号と反転 / 回転のフラグを持っています。

> **大きなマップの描画**。表示されている各チャンクは 1 回だけ描画されてキャッシュされます。パンするときは、
> キャッシュ済みのチャンクを再利用して描き直さないので、大きなマップでもスクロールが滑らかです。新しく表示された
> 領域の**最初の**描画は、バックグラウンドで先に準備されるので、追いつくまでのあいだも
> ウィンドウは応答したままです。

## Tiled JSON のエクスポート / インポート

マップは **Tiled 互換の JSON** にエクスポートでき、**欠落なく**再インポートできます — エクスポートして読み込み直しても、
レイヤー、すべてのセルとその反転 / 回転のフラグ、エディター自身が使わないフィールドが保持されます
(不明なフィールドも、そのまま引き継がれます)。

- **エクスポート** (**タイルマップ ▸ Tiled JSON をエクスポート…**) では、有効な Tiled マップが書き出され、
  レイヤーデータは **CSV** 形式で出力されます。
- **インポート** (**タイルマップ ▸ Tiled JSON をインポート…**) では、レイヤーデータが CSV、
  または圧縮なし / gzip / zlib の base64 で書かれた Tiled マップを読み込み、
  **外部の `.tsj`** タイルセット参照も受け付けます。
- インポートは**入力を検証する安全な読み込み**です。不正な形式のマップ、未対応の **zstd** 圧縮レイヤー、
  外部の **`.tsx`** タイルセット参照は、異常終了や、気づかないうちのデータ破損ではなく、
  明確なエラーとして拒否されます。

> **往復での忠実性**。不明なフィールドが往復後も残り、反転 / 回転のフラグがビット単位でそのまま
> 保たれるので、マップを PixelArt Creator と Tiled の間で行き来させても、
> もう一方のツールが追加したデータが失われることはありません。

## 保存と読み込み

タイルセットとタイルマップは、`.pixproj` に保存して読み込み直しても変わりません。プロジェクトを保存して開き直すと、
すべてのタイルセット (元の画像と分割の設定) と、すべてのタイルマップ (そのレイヤー、セル、
セルごとの反転 / 回転のフラグ) が、そのまま復元されます。以前のバージョン (タイルマップができる前) で保存した
プロジェクトも引き続き開けます — タイルセットやタイルマップがない状態で読み込まれるだけです。

## 元に戻す、やり直す、そして*元に戻せない*操作

- **元に戻せる操作 (それぞれ 1 ステップ)**：セルへのスタンプ / 消去、矩形塗りつぶし (オートタイルの隣接セルの再計算を含む)、
  タイルマップレイヤーの追加 / 削除 / 並べ替え / 表示 / 非表示。
- **元に戻せない操作 (表示状態)**：タイルセットエディターパネルでのタイルの選択、オートタイルの切り替え、
  次のスタンプの反転 / 回転の選択、マップのパン。

## 対象外の内容

- インポートでの **zstd 圧縮**の Tiled レイヤーデータと、**外部の `.tsx`** タイルセット — 仕様として拒否されます
  (インポートが受け付けるのは、CSV、base64 (圧縮なし / gzip / zlib)、外部の `.tsj` です)。対応しているエンコーディングのいずれかを使ってください。
- Blob-47 の隣接 8 セル方式を超える、**角 / 辺の Wang** タイルセット — オートタイルの処理は、後のフェーズでこれらに拡張できるように設計されています。
- **アニメーションタイル**と**オブジェクトレイヤー** — 後のフェーズで対応します。このリリースが対象とするのはタイルレイヤーです。
