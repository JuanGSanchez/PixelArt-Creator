# レイヤーパネル

**レイヤーパネル**には、現在のフレームについて、アクティブなドキュメントのレイヤーとグループが一覧され、
レイヤーごとのあらゆるコントロールが用意されています。非破壊編集の主な操作画面です。

## 一覧の見方

- レイヤーは**重ね順に上から下へ**表示されます。**一覧の一番上の行がスタックの最上部**です
  (最後に、つまり最前面に描画されます)。
- **アクティブなレイヤー**はちょうど 1 行で、ペイントツールの対象になります。
- **グループ**は、子レイヤーを含む、展開 / 折りたたみ可能なノードとして表示されます。

## レイヤーごとのコントロール

各レイヤーの行には次のコントロールがあります。

| コントロール | 動作 |
| --- | --- |
| **不透明度スライダー** | レイヤーの不透明度を **0–100%** で設定します。通常だけでなく、すべてのブレンドモードに適用されます。 |
| **表示の切り替え** | レイヤーを表示または非表示にします。非表示のレイヤーは合成結果に何も寄与しません。 |
| **ロックの切り替え** | レイヤーを**ピクセル**の変更から守ります。ロックされたレイヤーでは、ペイント / 塗りつぶし / 消去が何も行われなくなりますが、不透明度、表示、ブレンドモード、順序は変更できます。 |
| **ブレンドモードのドロップダウン** | 12 種類の[ブレンドモード](blend-modes.md)から 1 つを選びます。 |

> **ロックが守るのはピクセルだけです**。ロックされたレイヤーにもフォーカスでき、不透明度の変更、
> 表示 / 非表示の切り替え、並べ替えもできます。ロックが止めるのは、そのピクセルへの描画だけです。

## レイヤーの管理

- **レイヤーを追加** — アクティブなレイヤーの上に新しい空のレイヤーを挿入します。
- **レイヤーを削除** — アクティブなレイヤーを削除します。フレームの**最後の**レイヤーは
  削除できません。
- **レイヤーを複製** — ピクセルを丸ごと、属性もコピーしたレイヤーを、元のレイヤーの上に挿入します。
- **ドラッグで並べ替え** — 行を新しい位置にドラッグして重ね順を変えると、キャンバスは新しい順序で再合成されます。
  グループの中へ、またはグループの外へドラッグすると、レイヤーの親グループが変わります。

## グループ

- **グループ**は、選択した最上位階層のレイヤーを新しいグループノードで包みます。
- **グループ解除**はグループを解散し、その子レイヤーをグループの位置で親グループに引き上げます。

グループは**まず子レイヤーを合成**し、そのひとつにまとめた結果を、**グループ自身の**不透明度とブレンドモードで
スタックに重ねます。既定の属性 (通常、100%) のグループは、グループ化していない子レイヤーと同じ結果に合成されます。
グループを非表示にすると、その下のツリー全体が非表示になります。グループの入れ子の深さには上限があります。

## マスク

レイヤーに**マスク**を付けると、そのアルファを非破壊で調整できます。

1. 選択したレイヤーに対して**マスクを追加**を選びます。
2. **マスクを編集**をオンにして、マスクをペイント対象にします。以後のペイントは、レイヤーのピクセルではなくマスクのバッファーを編集します。
3. マスクが 0 の場所ではレイヤーは非表示、最大の場所では完全に表示され、中間の値では比例した表示になります。

最大値だけのマスクはマスクがない状態と同じで、マスクを編集してもレイヤー自身のピクセルは変わりません。
マスクの追加 / 削除は元に戻せます。

## リファレンスレイヤー

レイヤーの**リファレンス**をオンにすると、そのレイヤーが**リファレンス**レイヤーになり、その上からなぞれます。合成結果には表示されたままですが、
**ペイントを受け付けません** (ペイントツールは何も行いません)。目的を宣言した恒久的なロックのようなものです。
このフラグは元に戻せます。

## スマートレイヤー

**スマートレイヤー**を選ぶと、選択したソースレイヤーを元に、**スマートレイヤー**が作成されます。スマートレイヤーは非破壊のインスタンスで、
**ソースのピクセルを (読み取り専用で) そのまま反映**しつつ、独自の不透明度、表示、ブレンドモードを持ちます。
ソースを編集すると、次の再合成ですべてのスマートインスタンスが更新されます。
スマートレイヤーには、個別に編集できるピクセルはありません。

## どの操作も元に戻す 1 ステップ

パネルから行えるレイヤー操作はすべて、つまり不透明度 / 表示 / ロック / ブレンドモードの設定、
追加 / 削除 / 複製 / 並べ替え、グループ化 / グループ解除、マスクの追加 / 削除、
リファレンス / スマートの設定は、**ちょうど 1 つ**の元に戻すコマンドとして積まれます。
元に戻すと、レイヤーツリーは直前の状態に正確に戻ります。

## カラーモードとインデックスカラーのドキュメント

レイヤースタックとブレンドモードが適用されるのは **RGBA** のドキュメントです。**インデックスカラー**のドキュメントは
設計上 1 レイヤーのみです。合成処理は RGBA 専用だからです。

- **複数レイヤーの RGBA** ドキュメントをインデックスカラーに変換 (**パレット ▸ インデックスカラーに変換**) すると、**合成結果が (フレームごとに)
  1 つのインデックスカラーレイヤーに統合されます**。この操作は元に戻せます。元に戻すと、
  グループ、マスク、不透明度、ブレンドモード、リファレンス、スマートのリンクを含む複数レイヤーの RGBA ツリー全体が
  そのまま復元されます。
- RGBA に戻すと、1 つのインデックスカラーレイヤーが 1 つの RGBA レイヤーになります。

ドキュメントのカラーモードが唯一の基準なので、キャンバスの表示、
`.pixproj` に保存される内容、モードの表示は常に一致します。
