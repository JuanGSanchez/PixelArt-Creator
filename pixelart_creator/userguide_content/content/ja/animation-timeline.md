# アニメーションのタイムライン

**アニメーションシステム**は、ドキュメントのフレームの一覧を*タイムライン*に変えます。フレームの追加、
削除、並べ替え、複製ができ、フレームごとに画面上での表示時間を設定でき、
4 つのモードのいずれかでシーケンスを再生でき、オニオンスキンで前後のフレームを見ながら描け、
フレームタグでフレームの範囲を**名前付きアニメーション**にまとめられます。フレームやタグの編集は、
どれも元に戻せる 1 ステップになります。

タイムライン、再生、オニオンスキン、タグの機能は **Aseprite** と同等で、さらにフレームタグによって
**1 つのファイルに名前付きの独立したアニメーションを複数** (walk、run、idle など) 持てる点で、
それを上回ります。

> **フレームごとに独立したレイヤー**。各フレームは**専用の**レイヤースタックを持ち、同じ
> [レイヤーの仕組み](layers.md)で合成されます (表示 / 不透明度 / ブレンドモード / グループ /
> マスクはすべてフレームごとに反映されます)。**インデックスカラー**のドキュメントでは、フレームは 1 つの
> インデックスカラーレイヤーだけになり、オニオンスキンは表示されません (合成処理が RGBA 専用のため)。

## フレームストリップ

**タイムライン**パネルは、ドキュメントをフレームの横長のストリップとして再生順 (左から右) に表示します。
各セルにはサムネイル、フレーム番号、そのフレームにまたがるタグのマーカーが表示されます。
レイヤーパネルには、
現在アクティブなフレームのレイヤーが反映されます。

- **フレームの選択** — フレームをクリックします (または矢印キーを使います)。キャンバスには、そのフレームの
  合成されたレイヤースタックが表示されます。選択は表示操作なので、**元に戻せません**。
- **スクラブ** — ストリップに沿って押したままドラッグします。キャンバスには、カーソルの下にあるフレームが
  連続して表示されます。スクラブも**元に戻せません**。

## フレームの管理

タイムラインのツールバーでシーケンスを編集します。各操作は、**元に戻せるちょうど 1 ステップ**です。

| 操作 | 内容 |
| --- | --- |
| **フレームを追加** | アクティブなフレームの後ろに、レイヤーが空の新しいフレームを挿入します。 |
| **フレームを削除** | アクティブなフレームを削除します。**フレームが 1 つだけ残っているときは無効になります** — ドキュメントには常に 1 つ以上のフレームが残ります。 |
| **フレームを複製** | 元のフレームの後ろに、**独立した完全なコピー**を挿入します (レイヤーと表示時間もコピーされます)。コピーを編集しても元のフレームは変わりません。 |
| **フレームをドラッグ** | セルを新しい位置までドラッグして**並べ替え**ます。再生とスクラブは新しい順序に従います。 |

元に戻すと、以前のシーケンスがそのまま復元されます — 内容、順序、表示時間のすべてです。

## フレームごとの表示時間

各フレームには、ミリ秒単位の独自の**表示時間**があり、ストリップの表示時間の入力欄に表示されます
(新しいフレームの既定値は標準のフレーム表示時間です)。新しい値を入力して確定すると
(Enter キーを押すか、入力欄からフォーカスを外す)、そのフレームの表示時間が元に戻せる 1 ステップとして設定されます。
表示時間は**正の値**でなければなりません — 0 以下の値は拒否されます。
再生中、500 ms のフレームは 100 ms のフレームの約 5 倍の長さ表示されます。

> **一定のフレームレート**。一定の FPS とは、すべてのフレームに同じ表示時間を設定することにすぎません
> (`duration_ms = round(1000 / fps)`)。再生タイミングの唯一の基準は、
> 常にフレームごとのミリ秒の値です。

## 再生

**再生コントロール**が、表示されるフレームを時間に沿って切り替えます。

- **再生**は、ドキュメント全体の再生を開始します (一時停止からの再開も同じです)。
- **一時停止**は、現在のフレームで止めます。
- **停止**は、再生を止めて、再生を押したときにアクティブだったフレームに戻ります。
- **Space** キーで、再生 / 一時停止を切り替えます。

**再生モード**の選択欄で、シーケンスの進み方を選びます (既定は**ループ**)。

| モード | 4 フレームの範囲での動作 |
| --- | --- |
| **ループ** | `0,1,2,3,0,1,2,3,…` — 無限に繰り返します。 |
| **1 回** | `0,1,2,3` のあと、最後のフレームで**停止**します。 |
| **逆再生** | `3,2,1,0,3,2,1,0,…` — 逆方向に折り返します。 |
| **往復** | `0,1,2,3,2,1,0,1,2,3,…` — 行き来します。**両端は重複しません**。 |

再生は各フレーム自身の表示時間に従うので、表示時間を変更すると、
次に再生したときにそのフレームの画面上の時間が変わります。

> **大きなアニメーションの初回再生は、バックグラウンドで準備されます**。大きな (たとえば 8K の) 複数レイヤーの
> ドキュメントで範囲を初めて再生するときは、各フレームを平坦化した合成結果を 1 回作る必要があります。
> この処理は**バックグラウンド**で行われ、ステータスバーに小さな**キャンセル可能な**進行状況バーが表示されます — ウィンドウは応答したままで、
> 再生は固まることなく、準備ができたフレームから**順次表示**されます。
> フレームの準備が終わるとキャッシュされるので、再生し直したりスクラブしたりしても 60 fps で動作します。

## オニオンスキン

オニオンスキンは、編集中のフレームの背後に**前後のフレーム**を表示して、動きの位置合わせができるようにします。

- オニオンスキンパネルの**オニオンスキンを有効にする**チェックボックスで**有効**にします。ゴーストフレームはアクティブなフレームの背後に描画され、
  アクティブなフレーム自体は変わりません。
- 表示する**前**のフレームと**次**のフレームの数を設定します (それぞれ `0` にするとその側は無効になり、
  既定は**前 1 / 次 1** です)。
- 前側と次側それぞれの**色合い**を設定します — 既定では前が**赤**、次が**青**です。
  離れたフレームほど薄く表示されます。

オニオンスキンのフレーム数と色合いは**表示設定**です — 変更するとオーバーレイがリアルタイムで更新され、
元に戻すステップは**作られません**。オニオンスキンは**再生中は表示されません** (編集のための補助であり、
プレビューではないためです)。スクラブ中も表示されません。

## フレームタグ (名前付きアニメーション)

**フレームタグ**は、フレームの範囲に名前を付けて、独立したアニメーションにします。1 つのファイルに複数のタグを
持てます — たとえば、フレーム 1–4 にまたがる `walk` と、フレーム 0 だけの `idle` で、
タグ同士が重なってもかまいません。

**フレームタグ**パネルでは、次の操作ができます。

- **タグを追加 / タグを編集** — いずれもダイアログが開き、タグの**名前**、両端を含む**開始 / 終了**フレームの範囲、
  **再生モード**、**繰り返し**回数 (ループ系のモードでは `0` が無限)、**色**を指定します。
  **タグを削除**は、選択したタグをダイアログなしですぐに削除し、タグが選択されているときだけ使えます。
  どの変更も**元に戻せる 1 ステップ**です。タグは、対象のフレームにまたがる帯として表示されます。
- **タグを再生**は、選択したタグを名前付きの単独のアニメーションとして再生します。タグの範囲を、全体の再生モードとは
  無関係に、**タグ自身の**再生モードと繰り返し回数で実行します。モードが **1 回**で、繰り返しが 3 のタグは、
  範囲を 3 回再生してから停止します。

フレームを追加または削除すると、タグの範囲は自動的に有効な状態に保たれます
(新しいフレーム数の範囲に収められます)。
元に戻すと、フレームの変更と元のタグの範囲の両方がまとめて復元されます。

## グリッドビュー (セルグリッド)

タイムラインのツールバーにある**グリッドビュー**の切り替えで、横長のフレームストリップから**セルグリッド**に表示が変わります。
フレームが列、レイヤートラックが行になり、Aseprite のセルグリッドと同じスタイルです。
ストリップと同じドキュメントを表示するので、行き来しても作業位置を見失うことはありません。

- **セルの移動 / コピー** — 描画の入ったセルを押したままドラッグすると、新しいフレーム / トラックに移動します。
  ドラッグ中に **Ctrl** キーを押したままにすると、元のセルをその場に残したままコピーします。どちらも
  元に戻せる 1 ステップです。これはキャンバス上の **Ctrl+drag** とは**別の**操作です。キャンバス上の **Ctrl+drag** は
  今までどおりフローティング選択範囲をコピーします — [選択とフローティング移動 / コピー](selection-and-transform.md#copy-instead-of-move-hold-ctrl)を
  参照してください。修飾キーは同じでも、どちらが働くかはドラッグする場所で決まります。
- **上書きの確認** — すでに描画が入っているセルにドロップすると、**既存のセルを上書きしますか?** ダイアログが
  開きます。「**このプロジェクトでは今後確認しない**」チェックボックスをオンにすると、このプロジェクトでは
  それ以降確認されなくなります。この確認を再びオンにするには、下の
  [プロジェクトの確認](#project-confirmations)を参照してください。
- **セルごとの表示の切り替え** — セルの表示インジケーターをクリックすると、そのフレームのレイヤーの表示 / 非表示が
  切り替わります。ほかの場所での表示の切り替えと同じく、元に戻せる 1 ステップです。
- **セルの作成** — 空のセルを右クリックする (またはキーボードのコンテキストメニューキーを押す) と、
  「**ここにセルを作成**」アクションが表示されます。セルがすでに埋まっている場合や、フレームのレイヤー数が
  すでに上限に達している場合は、このアクションはまったく表示されません — メニューには、
  実行しても拒否されるだけのアクションは決して表示されません。
- **スクラブ** — 空のグリッドのセルをまたいでドラッグすると、表示するフレームをスクラブできます。
  ストリップに沿ってドラッグするのとまったく同じです。
- **列の並べ替え** — 列のヘッダーをドラッグしてフレームを並べ替えます。
  ストリップのセルをドラッグするのに相当する、グリッドでの操作です。

### プロジェクトの確認

グリッドビューの上書きの確認は、アプリのプロジェクト単位の設定のひとつです。「このプロジェクトでは今後確認しない」で
一度確認を止めると、**編集 ▸ プロジェクトの確認**から再びオンにするまで、そのプロジェクトでは確認されないままです。
ここには、止めたすべての確認が一覧表示され、それぞれを個別にオンに戻せます。

## ポインター操作

フレームストリップは、上の[フレームの管理](#managing-frames)にあるツールバーのボタンに加えて、
**Ctrl** キーと組み合わせる 4 つのポインター操作に応答します。

| 操作 | 結果 |
| --- | --- |
| **Ctrl+wheel** | アクティブなドキュメントの次 / 前のフレームに移動します。 |
| **Ctrl+middle-click** | アクティブなドキュメントのフレーム 1 に直接移動します。 |
| **Ctrl+left-click** | アクティブなフレームの後ろにフレームを追加します — **フレームを追加**ボタンと同じ、元に戻せる操作です。 |
| **Ctrl+right-click** | アクティブなフレームを削除します — **フレームを削除**ボタンと同じ、元に戻せる操作で、**タイムライン専用**です。グリッドビューには相当する操作がありません。ボタンと同様、ドキュメントに最後に残った 1 フレームには実行できません。ドキュメントには常に 1 つ以上のフレームが残るためです。 |

## 保存と読み込み

フレーム、フレームごとの表示時間、フレームタグは、いずれも `.pixproj` に保存して読み込み直しても変わりません。
タグ付きのアニメーションを保存して開き直すと、フレームの順序、すべてのフレームの表示時間、
すべてのタグが、そのまま復元されます。以前のバージョン (タグができる前) で保存したプロジェクトも
引き続き開けます — その場合はタグが空の状態で読み込まれます。

## 元に戻す、やり直す、そして*元に戻せない*操作

- **元に戻せる操作 (それぞれ 1 ステップ)**：フレームの追加 / 削除 / 並べ替え / 複製、フレームの表示時間の設定、
  タグの作成 / 編集 / 削除、そしてグリッドビューでのセルの移動 / コピー、セルの表示の切り替え、セルの作成。
- **元に戻せない操作 (表示状態)**：フレームの選択やスクラブ、再生 / 一時停止 / 停止、
  オニオンスキンのフレーム数や色合いの変更、ストリップとグリッドビューの切り替え。
