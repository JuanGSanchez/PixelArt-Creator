# 複数のキャンバス (アートボード)

複数のドキュメント / アートボードを同時に開けます。それぞれが専用の**タブ**に表示されます。

## 独立したタブ

開いているキャンバスは、それぞれ完全に**状態が独立**しています。タブが持つものは次のとおりです。

- レイヤーツリー (レイヤー、グループ、マスク、リファレンスレイヤー / スマートレイヤー)
- パレットとカラーモード
- 元に戻す / やり直す履歴
- 合成結果の表示とキャンバスの寸法

タブを切り替えると、そのキャンバスがアクティブなコンテキストになります。そのレイヤーツリー、パレット、
元に戻すスタック、合成結果が現在のものとなり、レイヤーパネルもそれに合わせて表示し直されます。

タブは独立しているため、あるキャンバスでの操作が別のキャンバスに影響することは**ありません**。
タブ A でのペイント、レイヤー属性の変更、並べ替え、グループ化、元に戻す操作は、
タブ B のツリー、合成結果、元に戻す履歴に一切触れません。

## アートボードをまたぐ作業

- アートボードごとに、キャンバスサイズ、パレット、カラーモードを変えられます。
- 元に戻す操作はタブごとです。元に戻してもアートボードをまたぐことはありません。
- ドキュメントを保存すると、そのタブ自身のレイヤーツリーが `.pixproj` ファイルに書き込まれます。

> **ヒント**。同じスプライトのバリエーション (たとえば色違いやポーズ) には別々のアートボードを使うと、
> それぞれの編集履歴が独立したままになります。

## 複数の*キャンバス*と複数の*ビュー*

複数のキャンバスは、それぞれ*別の*ドキュメントである**独立した**タブです。これは**マルチビュー**とは異なります。
マルチビューは、**1 つ**の共有ドキュメントに対して、互いに同期を保つ複数のウィンドウを開きます。
マルチビューでの編集は[表示補助と UX](visual-aids.md)を参照してください。
