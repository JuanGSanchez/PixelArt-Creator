# Начало работы и рабочая область

![PixelArt Creator](pac-logo.png)

Добро пожаловать в **PixelArt Creator** — настольную студию пиксель-арта с холстом 8K,
неразрушающей системой слоёв, временной шкалой анимации, редактором тайлсетов и тайлмэпов,
конвейером экспорта, автоматизацией и скриптами, утилитами, а также
инструментами для облака и совместной работы. Этот раздел знакомит с рабочей областью,
чтобы остальная часть руководства была понятна.

## Главное окно с первого взгляда

- **Строка меню** (сверху) — точка входа ко всем командам, сгруппированным в такие меню, как
  **Файл**, **Правка**, **Вид**, **Облако** и **Справка**. Встроенное руководство
  пользователя, которое вы сейчас читаете, открывается через **Справка ▸ Руководство пользователя**
  (или клавишей **F1**).
- **Холст** (в центре) — поверхность для рисования. См.
  [Холст: масштаб, панорамирование и сетка](canvas-and-view.md).
- **Панели** (по бокам) — панель слоёв, временная шкала анимации, панель редактора тайлсетов
  и панели облака и совместной работы. Большинство панелей можно включать и отключать
  и расставлять так, как удобно для вашей работы.
- **Строка состояния** (внизу) — индикаторы хода фоновых задач
  (экспорта, подготовки воспроизведения, сохранения в облаке) и краткие уведомления.

## Документы и вкладки

Каждый открытый рисунок — это **документ**, который показан в отдельной **вкладке**. У документа
есть размер, цветовой режим (**RGBA** или **индексированный**), палитра, дерево слоёв и —
если вы его анимируете — список кадров. Одновременно можно держать открытыми несколько
документов; см. [Несколько холстов (монтажные области)](multi-canvas.md). Документы
сохраняются как файлы проектов **`.pixproj`** — проверяемый версионированный формат сохранения,
которым пользуется всё приложение (и облачный слой).

## Отмена и повтор

Почти любая правка — рисование, изменение слоя, трансформация, правка кадра, запуск
автоматизации — помещается в **стек отмены** документа как **ровно один** шаг.
Действие **Отменить** отменяет последний шаг, а **Повторить** применяет его снова. История
отмены ведётся **отдельно для каждой вкладки**, поэтому отмена в одном документе никогда не
затрагивает другой. Ряд действий намеренно *не* отменяется, потому что это состояние вида,
а не правки: выбор кадра или перемотка по кадрам, включение калькирования, добавление
направляющей и открытие панелей облака и совместной работы.

## Темы (стиль, светлая и тёмная)

Всё, что касается внешнего вида приложения, находится в меню **Тема**. Каждый выбор
применяется сразу и запоминается до следующего запуска приложения.

- **Стиль** — подменю с тремя визуальными стилями: **Washi & Kintsugi** (по умолчанию),
  **Edo Night** и **Arcade Kikko**. Каждый из них — законченный внешний вид панелей,
  диалогов, рамок и узорных областей окна.
- **Светлая** / **Тёмная** — вариант оформления, который выбирается независимо от стиля. Все
  панели, диалоги, всплывающие элементы и это руководство пользователя отображаются
  правильно и остаются разборчивыми в обоих вариантах. Цвета задаются один раз по ролям,
  поэтому тема выглядит единообразно везде.
- **Использовать системный шрифт** — переключает интерфейс со встроенного пиксельного шрифта
  (Nifen Art) на шрифт интерфейса вашей операционной системы.
- **Пиксель-перфект для интерфейса** — включено по умолчанию. Интерфейс масштабируется
  только в целое число раз, поэтому пиксель-арт остаётся чётким на экранах с дробным
  масштабом (например, 125 % или 150 %). Изменение вступает в силу при следующем запуске
  приложения.

## Версия и сведения о программе

В заголовке окна всегда указано **PixelArt Creator** и номер запущенной версии — точный номер
вашей сборки, так что искать его не нужно. Подробные сведения откройте через
**Справка ▸ О программе PixelArt Creator** (в macOS — меню приложения рядом с пунктом
завершения работы: платформа размещает этот пункт именно там). В диалоге «О программе»
показаны название приложения, его версия (текст можно выделить, чтобы скопировать вручную),
лицензия, ссылки на репозиторий исходного кода, сайт документации и страницу релизов, а также
кнопка **Копировать**, которая помещает в буфер обмена одной строкой версию программы вместе
с версиями вашей операционной системы, Python и Qt/PySide6 — её можно сразу вставить в отчёт
об ошибке.

## Язык

Интерфейс полностью переводим. Когда вы меняете активный язык, все меню, подписи и сообщения
сразу переводятся заново — перезапуск не нужен. Интерфейс самого руководства (заголовок,
названия разделов, поле поиска и навигация) тоже следует активному языку; содержимое
руководства показывается на вашем языке, если в комплект входит локализованная версия,
а иначе используется текст по умолчанию (английский).

## Сочетания клавиш

Это полная таблица сочетаний клавиш приложения — все клавиши инструментов, оба переключателя,
два способа очистить выделение и основные действия с файлами, правкой и справкой. Каждая
другая страница руководства, где упоминается сочетание клавиш, ссылается на эту таблицу, а не
повторяет её.

| Сочетание | Действие |
| --- | --- |
| **A** | Карандаш — свободное рисование пикселей. |
| **Shift+A** | Пипетка — взять цвет с холста. |
| **Q** | Ластик. |
| **S** | Прямоугольник. |
| **W** | Линия. |
| **Shift+W** | Эллипс. |
| **D** | Прямоугольное выделение. |
| **F** | Заливка. |
| **Shift+F** | Дизеринг. |
| **E** | Выделение лассо (от руки). |
| **Shift+E** | Волшебная палочка (смежная область одного цвета). |
| **Shift+S** | Переключить **Заполненные фигуры** — общий режим для прямоугольника и эллипса. |
| **Shift+R** | Переключить **Пиксель-перфект** на холсте каждой открытой вкладки. |
| **Shift+Q** | Очистить содержимое выделения. |
| **Delete** | Очистить содержимое выделения (второе сочетание для того же действия). |
| **Ctrl+N** | Новый документ. |
| **Ctrl+O** | Открыть существующий проект. |
| **Ctrl+S** | Сохранить активный проект. |
| **Ctrl+Z** | Отменить последнюю обратимую операцию. |
| **Ctrl+Y** | Повторить последнюю отменённую операцию. |
| **F1** | Открыть это руководство пользователя. |

Одиннадцать клавиш инструментов специально расположены на домашнем ряду и рядом с ним, чтобы
во время рисования рука не покидала положения для набора текста. **Shift+Q** и **Delete**
делают одно и то же — очищают содержимое выделения, — поэтому можно нажать ту клавишу,
которая ближе к руке.

Ещё несколько сочетаний описаны на страницах, к которым они относятся, потому что их смысл
понятен только вместе с функцией: **Ctrl+Shift+E** открывает экспорт, см.
[Экспорт и интеграция с конвейером](export-and-pipeline.md); **Ctrl++** / **Ctrl+-**
изменяют масштаб холста, а жесты указателя, которые панорамируют, меняют масштаб и берут
цвета колесом или средней кнопкой, описаны на странице [Холст](canvas-and-view.md);
**Ctrl+A** / **Ctrl+I** / **Ctrl+Shift+A** / **Shift+H** / **Shift+V** и жесты перетаскивания
выделения — в разделе [Выделение и плавающее перемещение/копирование](selection-and-transform.md);
**Ctrl+wheel**, **Ctrl+middle-click**, **Ctrl+left-click** и **Ctrl+right-click** на временной
шкале — в разделе [Временная шкала анимации](animation-timeline.md).
**Space** переключает воспроизведение и паузу анимации и вообще не является сочетанием меню —
оно работает только при открытом документе с несколькими кадрами. **Esc** отменяет,
а **Enter** подтверждает любое выполняемое действие (чаще всего перемещение плавающего
выделения); что именно сюда входит, описано в разделе
[Выделение и плавающее перемещение/копирование](selection-and-transform.md).
