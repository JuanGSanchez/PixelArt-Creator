# 入门与工作区

![PixelArt Creator](pac-logo.png)

欢迎使用 **PixelArt Creator** 桌面像素画创作工具。它集成了 8K 画布、非破坏性
图层系统、动画时间轴、瓦片集与瓦片地图编辑器、导出管线、自动化与脚本、视觉辅
助工具，以及云端与协作工具。本主题带你了解工作区，帮助你理解本指南的其他内
容。

## 主窗口一览

- **菜单栏**（顶部）：所有命令的入口，按菜单分组，例
  如**文件**、**编辑**、**视图**、**云端**和**帮助**。你当前查看的应用内用户
  指南可通过**帮助 ▸ 用户指南**打开，也可以按 **F1** 打开。
- **画布**（中间）：绘图区域。参
  见[画布：缩放、平移与网格](canvas-and-view.md)。
- **面板**（左右）：图层面板、动画时间轴、瓦片集编辑器面板，以及云端和协作面
  板。大多数面板都可以打开或关闭，也可以按你的需要自行排列。
- **状态栏**（底部）：显示后台任务（导出、播放准备、云端保存）的进度，以及临
  时提示。

## 文档与标签页

每个打开的绘图都是一个**文档**，显示在独立的**标签页**中。文档具有尺寸、颜色
模式（ **RGBA** 或**索引**）、调色板、图层树，如果制作动画，还有一个帧列表。
你可以同时打开多个文档，参见[多个画布（画板）](multi-canvas.md)。文档
以 **`.pixproj`** 项目文件的形式保存，这是整个应用（和云端层）使用的、已校
验、带版本号的保存格式。

## 撤销与重做

绝大多数编辑（绘制、图层更改、变换、帧编辑、自动化运行）都只会作为**一个**步
骤加入文档的**撤销历史记录**。**撤销**会还原最近的一步，**重做**会重新应用
它。撤销历史记录**按标签页**独立保存，因此在一个文档中撤销绝不会影响另一个文
档。少数操作被明确设为*不可*撤销，因为它们属于视图状态而非编辑：选择帧或拖动
浏览帧、切换洋葱皮、添加参考线，以及打开云端和协作面板。

## 主题（样式、浅色与深色）

与应用程序样子有关的所有设置都集中在**主题**菜单中。每项选择都会立即生效，并
在你下次启动应用程序时保留。

- **样式**：一个子菜单，有三种视觉样式：默认的 **Washi & Kintsugi** 样式，以
  及 **Edo Night** 和 **Arcade Kikko** 样式。每种样式都是面板、对话框、边框
  和窗口图案区域的一套完整的视觉效果。
- **浅色** / **深色**：颜色模式，与样式独立选择。所有面板、对话框、浮层以及
  本用户指南在两种模式下都能正确显示，并保持可读。颜色按角色统一指定，因此主
  题在所有位置都保持一致。
- **使用系统字体**：把界面使用的内置像素字体 Nifen Art 切换为操作系统的界面
  字体。
- **像素完美界面**：默认开启。它只按整数倍缩放界面，因此在缩放比例
  为 125% 或 150% 等小数的显示器上，像素画的边缘也能保持分明。更改会在你下次
  启动应用程序时生效。

## 版本与关于

窗口标题始终显示 **PixelArt Creator** 及其后的当前版本号，即你所用版本的确切
编号，无需任何额外步骤即可查看。要查看完整内容，请选
择**帮助 ▸ 关于 PixelArt Creator** 菜单项。在 macOS 上，这一项位于应用程序菜
单中，与“退出”相邻，这是该平台放置该项的位置。“关于”对话框会显示应用名称、版
本（可选中，因此你可以手动复制）、许可证、指向源代码仓库、文档网站和发行版页
面的链接，以及一个**复制**按钮，它会把版本号连同你的操作系统版本，以
及 Python 和 Qt/PySide6 的版本放在一行中复制到剪贴板，可直接粘贴到错误报告
中。

## 语言

界面可以完整翻译。切换当前语言后，所有菜单、标签和消息都会实时重新翻译，无需
重启。本用户指南的外围界面（标题、章节标签、搜索框和导航）会随当前语言切换；
如果内置了本地化版本，指南内容会以你的语言显示，否则回退到默认的英文文本。

## 键盘快捷键

下表是应用程序键盘快捷键的完整列表，其中有所有工具键、两个开关、清除选区的两
种方式，以及基本的文件、编辑和帮助操作。本指南中提到键盘快捷键的其他页面都会
链接回此表，而不是重复列出。

| 快捷键 | 操作 |
| --- | --- |
| **A** | 铅笔工具，手绘像素。 |
| **Shift+A** | 取色器工具，从画布上取色。 |
| **Q** | 橡皮擦工具。 |
| **S** | 矩形工具。 |
| **W** | 直线工具。 |
| **Shift+W** | 椭圆工具。 |
| **D** | 矩形选框工具。 |
| **F** | 填充工具。 |
| **Shift+F** | 抖动工具。 |
| **E** | 套索选择工具（手绘）。 |
| **Shift+E** | 魔棒工具（连续颜色）。 |
| **Shift+S** | 切换**填充形状**，矩形工具和椭圆工具共用。 |
| **Shift+R** | 在每个已打开标签页的画布视图上切换**像素完美**。 |
| **Shift+Q** | 清除选区内容。 |
| **Delete** | 清除选区内容（同一操作的另一个快捷键）。 |
| **Ctrl+N** | 新建文档。 |
| **Ctrl+O** | 打开现有项目。 |
| **Ctrl+S** | 保存当前项目。 |
| **Ctrl+Z** | 撤销上一个可撤销的操作。 |
| **Ctrl+Y** | 重做上一个被撤销的操作。 |
| **F1** | 打开本用户指南。 |

上表中的 11 个工具键被安排在键盘中间一行及其相邻的按键上，这样你在绘制时手无
需离开打字位置。另外 **Shift+Q** 和 **Delete** 作用相同，都是清除选区内容，
所以用手边更近的一个即可。

还有一些快捷键放在它们所属的页面中，因为这些快捷键要结合相应的功能来理
解： **Ctrl+Shift+E** 打开导出，参
见[导出与管线集成](export-and-pipeline.md)； **Ctrl++** / **Ctrl+-** 用于缩
放画布，通过滚轮或中键来平移、缩放和取色的鼠标手势，参
见[画布](canvas-and-view.md)； **Ctrl+A** / **Ctrl+I** / **Ctrl+Shift+A** / **Shift+H** / **Shift+V** 以
及选区拖动手势，参见[选区与浮动移动/复制](selection-and-transform.md)；时间
轴上
的 **Ctrl+wheel** / **Ctrl+middle-click** / **Ctrl+left-click** / **Ctrl+right-click** 操
作，参见[动画时间轴](animation-timeline.md)。另外 **Space** 用于切换动画的播
放 / 暂停，它根本不是菜单快捷键，只在打开了多于一帧的文档时有效。
按 **Esc** 取消、按 **Enter** 确认当前正在进行的操作（最常见的是浮动选区的移
动），具体涵盖的内容，参
见[选区与浮动移动/复制](selection-and-transform.md)。
