# 瓦片集、瓦片地图与自动拼贴

**瓦片地图系统**可以把一张源图像变成可重复使用的**瓦片集**，并可以在**多图层的无
限地图**上用这些瓦片绘制大型关卡：把图像切分为带索引的瓦片，盖章 / 擦除 / 填充单
元格，由**自动拼贴**替你处理边界，放置时翻转和旋转瓦片，并把整张地图**导出 / 导
入**为兼容 Tiled 的 JSON 格式。每一次地图编辑都是单个撤销步骤。

> **逻辑瓦片与显示瓦片**。自动拼贴会把你*放置*的瓦片（**逻辑**瓦片）与*显示*出来
> 的瓦片（**显示**瓦片）区分开。你只需绘制一块“墙”瓦片，地图会根据相邻瓦片选出正
> 确的边缘 / 转角变体；真正被存储并能原样读回的是逻辑放置，因此结果**确定、可
> 逆**。关闭自动拼贴后，则直接显示逻辑瓦片。

## 瓦片集

**瓦片集**是一张被切分成网格的源图像，网格中的瓦片大小相同。打开**瓦片集编辑
器**面板（瓦片地图菜单），并添加瓦片集：**瓦片地图 ▸ 从图像新建瓦片集…**；切分器
会按你设置的**瓦片大小**、可选的外围**边距**和瓦片之间的**间距**读取图像，并
从 `0` 开始，按从左到右、从上到下的顺序为生成的瓦片编号。

- 每个瓦片都是源缓冲区中的一个区域，因此瓦片集**以一张图像为基础**，而不是许多个
  副本。
- **编辑源瓦片会同步更新**该瓦片在每个图层中所有已放置的实例：只需重新绘制一次瓦
  片，整个关卡会随之更新。
- 面板会把切分后的瓦片显示为一个选取网格；所选的瓦片是图章工具绘制的瓦片。

> **边距与间距**。参数 `margin` 指在整张图像外围跳过的边框；参数 `spacing` 指在
> 瓦片**之间**跳过的空白。导出时带有 1px 间隔的瓦片表，通常需要设
> 置 `spacing = 1` 这一项；如果图像边缘也带有间隔，则还要设置 `margin = 1` 这一
> 项。这样，切分器才能精确地对准每个瓦片。

## 绘制瓦片地图

**瓦片地图画布**在网格上绘制单元格，每个单元格放一块瓦片。先在瓦片集编辑器面板中
选取一个瓦片，再使用这些地图工具：

| 工具 | 作用 |
| --- | --- |
| **图章工具** | 把所选瓦片放入光标下的单元格（拖动即可连续放置多个）。 |
| **瓦片橡皮擦** | 把单元格清除为空。 |
| **矩形填充** | 用所选瓦片填充你拖出的矩形。 |

每一次盖章 / 擦除 / 矩形填充都**只算一个撤销步骤**，撤销会精确恢复之前的单元格。
在已有瓦片附近绘制时，会重新计算**自动拼贴**的相邻区域，使边界在你绘制时始终保持
正确。

### 翻转与旋转

盖章之前，你可以先变换瓦片：**水平翻转图章**和**垂直翻转图章**会对它做镜像，
而**顺时针旋转图章 90°** 会依次切换它的四个直角方向。这种变换会作为瓦片上的一个
小标志，按每个已放置的单元格保存，因此翻转或旋转瓦片**不需要额外的瓦片集条目**，
并可以无损地保存并读回。变换按固定顺序组合（先对角，再水平，最后垂直），因此同一
种组合总是渲染出完全相同的结果。

## 自动拼贴

**自动拼贴**会根据每个单元格的 **8 个相邻单元格**来确定它的*显示*瓦片
（即 Blob-47 方案：采用 8 邻域位掩码，并带有“边缘蕴含转角”的约束条件，共得
到 47 种不同的瓦片）。只需绘制一块“地形”瓦片，地图即可自动补出正确的直边、内角和
外角。

- 在瓦片地图图层面板中，勾选或取消勾选复选框**自动拼贴(Blob-47)**，即可**切
  换**自动拼贴。**开启**时，绘制、擦除或矩形填充还会重新计算受影响的单元格**及其
  相邻单元格**，使边界始终保持一致，这一切都包含在同一个撤销步骤之中。
- 确定显示瓦片的过程**完全由逻辑放置和相邻瓦片决定**，因此同一张地图总是渲染出相
  同的显示瓦片。
- **关闭**自动拼贴会直接显示你放置的逻辑瓦片，不进行边界处理。

## 图层与无限地图

瓦片地图是**多图层**的：你可以叠放背景、地形和细节图层，每个图层都独立绘制，所用
的图层模型与编辑器其他部分相同（添加 / 移除 / 重新排序 / 显示 / 隐藏）。**瓦片地
图图层**面板用于管理这个图层堆栈；可见的图层会合成在一起用于显示。

地图的范围是**无限**的：单元格以 **16×16 区块组成的稀疏网格**的形式存储，因此只
有你实际绘制过的区域才会占用内存。你可以在远离原点的位置（任何方向都行）盖章，而
无需预先设定地图大小，空白区域不占用任何资源。每个单元格都是一个 32 位的瓦片标识
（即 GID 值），其中记录瓦片索引及其翻转 / 旋转标志。

> **大型地图的渲染**。每个可见区块只渲染一次并缓存；平移时会复用缓存的区块而不是
> 重新绘制，因此滚动大型地图时同样流畅。新近变为可见的区域，其**首次**绘制会在后
> 台预先完成（在 GUI 线程之外进行），这样窗口在处理期间还能保持响应。

## Tiled JSON 导出 / 导入

地图可以导出为**兼容 Tiled 的 JSON 格式**，并可以**无损地**重新导入：往返一次会
保留所有图层、每个单元格及其翻转 / 旋转标志，以及编辑器不使用的任何字段（未知字
段会原样保留）。

- **导出**（**瓦片地图 ▸ 导出 Tiled JSON…**）会写出有效的 Tiled 地图，图层数据
  为 **CSV** 格式。
- **导入**（**瓦片地图 ▸ 导入 Tiled JSON…**）可以读取以 CSV 写出的 Tiled 地图，
  也可以读取图层数据为 base64 编码（未压缩，或用 gzip 或 zlib 压缩）的 Tiled 地
  图，并接受**外部 `.tsj`** 瓦片集引用。
- 导入是一种**防御性的、带校验的加载**：格式错误的地图、不受支持的 **zstd** 压缩图
  层，或外部的 **`.tsx`** 瓦片集引用，都会被拒绝并给出明确的错误，而不会导致崩溃
  或悄悄损坏数据。

> **往返保真度**。由于未知字段在往返过程中会保留下来，翻转 / 旋转标志也会按位保
> 留，因此你可以在 PixelArt Creator 与 Tiled 之间来回移动地图，而不会丢失另一个
> 工具添加的数据。

## 保存与重新打开

瓦片集和瓦片地图都会随 `.pixproj` 文件保存并读回。保存后再重新打开项目，会原样恢
复每个瓦片集（它的源图像和切分配置）和每张瓦片地图（它的图层、单元格以及每个单元
格的翻转 / 旋转标志）。先前版本（尚无瓦片地图时）保存的项目还是可以打开，只是加
载后没有瓦片集或瓦片地图。

## 撤销、重做与*不可*撤销的操作

- **可撤销（每项一步）**：盖章 / 擦除单元格，矩形填充一个区域（包括任何自动拼贴
  相邻区域的重新计算），以及添加 / 移除 / 重新排序 / 显示 / 隐藏瓦片地图图层。
- **不可撤销（视图状态）**：在瓦片集编辑器面板中选取瓦片，切换自动拼贴，为下一次
  盖章选择翻转 / 旋转，以及平移地图。

## 未涵盖的内容

- **zstd 压缩**的 Tiled 图层数据和**外部 `.tsx`** 瓦片集在导入时会按设计被拒绝：
  导入接受 CSV 编码，以及未压缩，或用 gzip 或 zlib 压缩的 base64 编码，并接受外
  部 `.tsj` 瓦片集；请改用受支持的编码之一。
- 超出 Blob-47 的 8 邻域方案的**角 / 边 Wang** 瓦片集：自动拼贴功能的设计允许在
  以后的阶段扩展到它们。
- **动画瓦片**和**对象图层**：留待后续阶段；当前版本只涵盖瓦片图层。
