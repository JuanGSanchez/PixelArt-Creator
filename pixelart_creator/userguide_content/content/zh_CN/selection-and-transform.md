# 选区与浮动移动/复制

选择一个区域可以使你只处理画面的一部分，而**浮动选区**则可以使你提起当前选区
内的颜色，并以**实时、非破坏性的预览**方式移动或复制它们。在你确认之前，浮动
选区*下方*的像素**不会改变**，因此移动操作总是可以安全地重新定位或放弃。

这与你在 Aseprite / Pro Motion NG / Pixelorama / Krita 等工具中使用过的行为
一致：提起、拖动、放下。

> **仅作用于当前图层**。浮动的移动/复制只作用于**当前图层**（参
> 见[图层面板](layers.md)）。在索引文档中，当前图层即该文档中单独的索引图
> 层。其他图层不受影响。

## 创建选区

使用选区工具来指定你要处理的区域：

| 工具 | 选中的内容 |
| --- | --- |
| **矩形选框** | 拖出的矩形区域。 |
| **套索选择** | 手绘出的自由区域。 |
| **魔棒** | 单击处下方颜色相近的连续区域。 |

**选区的保留方式**。切换到以上三种选区工具之一，始终会**丢弃**当前选区并重新
开始，新选区绝不会带有上一个选区的形状。切换到任何其他工具（铅笔、橡皮擦、填
充…）则会**保留**当前选区，所以受蒙版约束的绘制可以继续进行：你用其他工具绘
制时，笔画也会被限制在选区内。

以上三种选区工具之一为当前工具时，修饰键 **Shift** 和 **Alt** 的作用与画布上
的其他场合不同，参见下文
的[平移与创建选区](#panning-vs-building-a-selection)：

| 修饰键 | 当前工具为选区工具时的结果 |
| --- | --- |
| **Shift**+drag | **添加**到当前选区。 |
| **Alt**+drag | 从当前选区中**减去**。 |

### 平移与创建选区

| 手势 | 结果 |
| --- | --- |
| **Shift+left-drag** | 平移画布；**例外**是当前工具为选区工具时，此时它会改为向选区中**添加**，与上表完全一致。 |

### 全选画布、反转与清除

| 快捷键 | 操作 |
| --- | --- |
| **Ctrl+A** | 选择整个画布。 |
| **Ctrl+I** | 反转当前选区。 |
| **Ctrl+Shift+A** | 取消选择（清除当前选区）。 |

清除选区的**内容**（而不是选区）是另一个独立的操作，它有单独
的 **Shift+Q** 和 **Delete** 两个快捷键，参见[应用基础](app-basics.md)中的表
格。

## 提起并移动（拖动）

浮动操作提起的是当前已有的选区，它**不会**创建新的选区形状，而是复用你已有的
蒙版。

1. 在某个选区工具（矩形选框、套索选择或魔棒）为当前工具时，在当前选
   区**内部按下**。被蒙版覆盖的像素会被提起，成为浮动预览。
2. **拖动**。浮动的颜色会随光标移动；在实时预览中，原区域显示
   为**已清除为透明**（索引模式下为 0 号索引）。
3. 下方的像素**尚未被修改**，只有预览发生了变化。

在当前选区**外部**按下**不会**提起内容，而是照常开始创建新选区。

## 改为复制而非移动：按住 Ctrl

拖动时按住 **Ctrl** 即可把浮动选区切换为**复制**模式：

- **原位置保持不变**（不会清空任何内容）
- 颜色的**副本**会浮动到光标处

复制模式下的光标 / 提示会表明你正在复制。你可以在拖动**过程中**，通过按下或
松开 Ctrl 在移动与复制之间切换。

> **只有 Ctrl 是复制修饰键， Alt 不是**。复
> 制**只能用 Ctrl 来完成**。**修饰键 Alt 不能用来复制**：在选区内部按
> 住 Alt 拖动，是创建选区时的**减去**手势，并保持这一作用。在内部拖动时同时
> 按住 **Ctrl+Alt** 会被解析为 Alt 减去，而不是复制，请只按 **Ctrl** 来复
> 制。

| 内部拖动 | 结果 |
| --- | --- |
| *无修饰键* | 提起 / **移动**选区（确认时原位置被清空） |
| **Ctrl** | **复制**选区（保留原位置） |
| **Alt** | 从选区中**减去**（创建手势） |
| **Shift** | **添加**到选区（创建手势）；而当前工具不是选区工具时，按 **Shift+left-drag** 会改为平移而不是添加，参见上文的[平移与创建选区](#panning-vs-building-a-selection)。 |

## 确认或取消

浮动选区会在以下任一操作时**确认**：

- **松开**鼠标按钮
- 按下 **Enter / Return**
- **切换工具**（或切换画布标签页）

确认时，更改会作为**仅一个**可撤销的步骤应用：

- **移动**：原位置被写为透明（索引模式下为 0 号索引），颜色则被绘制到目标位
  置。
- **复制**：颜色被绘制到目标位置，原位置保持不变。

确认之后，选区蒙版会**移到目标位置**。

按 **Esc** 可**取消**。由于浮动选区从未写入缓冲区，取消会**精确地**恢复移动
之前的画布，并**不会**记录任何撤销条目；选区蒙版会回到提起之前的位置。

> **不拖动的单击不产生任何开销**。在没有位移时确认（在选区内部单击而没有移
> 动）不会产生任何效果，也不会创建撤销步骤。

如果目标位置已有像素，会先出现对话框 **覆盖现有像素?**，由它来询
问：**继续**会照常应用确认，**取消**则不应用任何内容，并使浮动选区保持在当前
位置。勾选“**此项目不再询问**”后，如果你确实接受，这项选择会被记录；如果勾选
后再取消，则不会记录任何内容。

## 画布外的边缘

你可以把浮动选区**部分或完全拖到画布之外**。确认时，画布外的像素会
被**丢弃**（不会从另一边重新出现），因此你可以放心地把图像放到边缘而不会出
错。对于移动，无论你拖动的位移有多大，位于边界内的整个原区域同样会被清空。

## 撤销、重做与渲染

- 一次已确认的移动或复制是**一个**撤销步骤：**撤销**会精确恢复移动之前的缓冲
  区；**重做**会重新应用它。
- 浮动预览在任何缩放比例下都以**最近邻并关闭抗锯齿**的方式渲染，并
  在**浅色**和**深色**主题中都能看清。
- 实时拖动预览只更新浮动选区所在的区域，所以即使在 8K 画布上，它也能保持
  在 16ms / 60fps 的帧预算之内。

## 整个文档的变换

只要没有选区，**图像 ▸ 缩放…**、两个 90° 旋转操作和两个翻转操作都会作用
于**整个文档**，即每一帧中的每个图层和蒙版。存在选区时，这些操作还是只变换当
前图层中被蒙版覆盖的区域，与以前完全一样。

| 快捷键 | 操作 |
| --- | --- |
| **Shift+H** | 水平翻转选区（或整个文档）。 |
| **Shift+V** | 垂直翻转选区（或整个文档）。 |

RotSprite 是一个例外：无论有没有选区，它始终只变换当前图层，因为它的旋转从不
会改变缓冲区的尺寸，也从来不需要更大的作用范围。

> **大型变换会先询问**。当重采样后的结果与为撤销保留的缓冲区加在一起，将多
> 于 506.25MiB 的内存（相当于 4 个完整 8K 画布的 RGBA 数据量）时，会出
> 现**确认大型变换**对话框，在任何操作运行之前给出确切的内存占用。**取消**是
> 默认按钮，因此按下 Return **不会**启动变换，你必须明确地单击**继续**。拒绝
> 会使文档完全保持原样，也不会向撤销历史记录中加入任何内容。未达到该上限时，
> 根本不会出现任何对话框。

整个文档的变换开始运行后，**正在变换文档**进度对话框会依次按缓冲区显示进度，
并可通过取消按钮、窗口自带的关闭控件或 Escape 在任何时刻取消。取消是原子的：
文档会完全保持原样，无论此前重采样了多少个缓冲区，都不会有任何内容进入撤销历
史记录。

## 未涵盖的内容

- 在选区*浮动时*对它进行**旋转或缩放**：请先确认移动，再使用变换工具。
- **移动所有图层**的变体：浮动选区仅作用于当前图层。
- 浮动选区的**跨文档**拖动，或把浮动选区保存到 `.pixproj` 中：浮动选区是一种
  临时的编辑状态，总是要先确认或取消。
