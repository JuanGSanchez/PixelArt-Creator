# 图层面板

**图层面板**会列出当前文档在当前帧中的图层和图层组，并具有每个图层的所有控
件。它是进行非破坏性编辑的主要界面。

## 查看图层列表

- 图层按**叠放顺序自上而下**显示：**列表顶部的一行即堆栈的顶层**（最后绘
  制 / 位于最前）。
- 只有一行是**当前图层**，它是绘制工具的作用对象。
- **图层组**显示为展开 / 收起的节点，其中有它们的子项。

## 图层控件

每个图层行都有：

| 控件 | 作用 |
| --- | --- |
| **不透明度**滑块 | 在 **0–100%** 的范围内设置图层的不透明度。对每一种混合模式都有效，而不仅限于正常模式。 |
| **可见性**开关 | 显示或隐藏图层。隐藏的图层不会对合成结果产生任何影响。 |
| **锁定**开关 | 防止图层的**像素**被修改。已锁定图层的绘制、填充和清除都不会产生任何效果，不过它的不透明度、可见性、混合模式和顺序也可以更改。 |
| **混合模式**下拉列表 | 从 12 种[混合模式](blend-modes.md)中选择一种。 |

> **锁定只作用于像素**。你也可以使已锁定的图层获得焦点、更改其不透明度、隐
> 藏 / 显示它以及重新排序。锁定只会禁止向其像素中绘制。

## 管理图层

- **添加图层**：在当前图层上方插入一个新的空图层。
- **移除图层**：删除当前图层。不允许移除一帧中的**最后一个**图层。
- **复制图层**：在源图层上方插入一个像素完全一致的副本，并复制其属
  性。
- **拖动重排**：把某一行拖到新位置即可更改叠放顺序，画布会按新顺序重新合成。
  拖入或拖出图层组会更改该图层的父级。

## 图层组

- **组**会把所选的顶层图层放入一个新的组节点。
- **取消编组**会解除一个图层组，把它的子项移到父级中该图层组所在的位置。

图层组会**先合成它的子项**，再使用**该图层组单独的**不透明度和混合模式，把这
一个拼合后的结果混合到堆栈之上。属性为默认值（即正常模式和 100% 不透明度）的
图层组，其合成结果与未编组的子项完全相同。隐藏图层组会隐藏它的整个子树。图层
组的层级数量是有限的。

## 蒙版

为图层附加**蒙版**，以非破坏性的方式调制其 Alpha 通道：

1. 对所选图层选择**添加蒙版**。
2. 打开**编辑蒙版**，使蒙版成为绘制目标：此时绘制编辑的是蒙版缓冲区，而不是
   图层的像素。
3. 蒙版值为 0 的地方，图层被隐藏；达到最大值的地方，图层完全显示；中间值则按
   比例显示。

全部为最大值的蒙版等同于没有蒙版，编辑蒙版也绝不会更改图层的像素。附加 / 移
除蒙版是可以撤销的。

## 参考图层

打开**参考**，可把图层标记为**参考**图层，用来照着它绘制：它在合成结果中保持
可见，同时**拒绝绘制**（绘制工具对它不起作用），如同一个明确声明的永久锁定。
该标记是可逆的。

## 智能图层

使用**智能图层**，可以基于所选的源图层创建一个**智能图层**。智能图层是一个非
破坏性的实例，它**同步显示源图层的像素**（只读），同时具有独立的不透明度、可
见性和混合模式。编辑源图层会在下一次重新合成时更新每一个智能实例；智能图层没
有可独立编辑的像素。

## 一切都是一个撤销步骤

面板中的每一项图层操作（设置不透明度 / 可见性 / 锁定 / 混合模式、添加 / 移
除 / 复制 / 重排、编组 / 取消编组、附加 / 移除蒙版、设置参考 / 智能）都只会
作为**一条**撤销命令加入历史记录。撤销会把图层树精确地恢复到之前的状态。

## 颜色模式与索引文档

图层堆栈和混合模式适用于 **RGBA** 文档。**索引**文档按设计只有一个图层，因为
合成器仅支持 RGBA 格式。

- 把**多图层 RGBA** 文档转换为索引色（**调色板 ▸ 转换为索引色**）时，
  会**把合成结果拼合为单个索引图层**（每帧一个）。这个操作可以撤销：撤销会精
  确恢复完整的多图层 RGBA 图层树，图层组、蒙版、不透明度、混合模式、参考和智
  能链接都不会丢失。
- 转换回 RGBA 时，这个单一的索引图层会变成一个 RGBA 图层。

画布显示的内容、保存到 `.pixproj` 的内容以及模式指示器，都只以文档的颜色模式
为准，因此始终一致。
