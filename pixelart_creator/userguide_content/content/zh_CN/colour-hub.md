# 右键颜色中心

**颜色中心**是一个上下文菜单，你可以**在工作的地方随时打开**：在画布
上**右键单击**，它会在光标处打开。它有两种快速选色的方式：一个精选
的**收藏夹**列表，以及一个带有实时**颜色理论配色**的完整**色轮**，并会立即应
用你的选择。

## 打开颜色中心

在[画布](canvas-and-view.md)的任何位置右键单击。颜色中心会固定在光标处出现，
因此你无需前往其他位置的面板更改颜色。选取一种颜色后，它会立即成
为**当前颜色**，当前颜色色板也会随之更
新。**颜色中心打开时再次右键单击会将其关闭**而不选取任何颜色，这样你可以退出
并从原处继续绘制。

## 收藏夹

**收藏夹**是你个人的、会被持久保存的常用颜色列表。

- **添加到收藏夹**会把当前颜色保存在收藏夹中，下次只需一次单击即可取用。
- **移除**你不再需要的颜色。
- **上移** / **下移**用于重新排列收藏项，使你最常用的颜色排在最前面。

你的收藏夹列表会在不同会话之间**保持不变**，因此重新打开应用时，你的常用调色
板始终都在。单击某个收藏项会立即应用它。

还有一个手势，无需打开颜色中心即可访问收藏夹：

| 手势 | 结果 |
| --- | --- |
| **Middle-click** | 当场选中收藏夹中的第一项并将其设为当前颜色，无论颜色中心是否已打开。 |

## 色轮

**色轮**是 Canva 样式的 RGB 色轮，可按色相和饱和度选取任何颜色，并带有明度
（亮度）控件。在色轮上移动时，当前颜色会实时更新。

## 实时颜色理论配色

在色轮上选色时，颜色中心会显示根据你的当前颜色、按标准颜色理论得出
的**配色色板**，使你无需试错即可创建协调一致的调色板：

| 配色 | 与你所选颜色的关系 |
| --- | --- |
| **互补色** | 位于相反色相 +180° 处，对比最大。 |
| **邻近色** | 位于相邻色相 ±30° 处，形成平和、统一的配色。 |
| **三角配色** | 相距 ±120° 的两种色相，协调而生动。 |
| **四角配色** | 以 90° 的等间隔分布的三种色相，组成四色、高对比的配色。 |
| **分裂互补色** | 位于互补色两边 ±150° 处的两种色相。 |
| **暗色调**和**亮色调** | **暗色调**是你所选颜色较暗的层级，**亮色调**是较亮的层级。**明暗色阶**面板（从**调色板**菜单打开）会为你的当前颜色铺开完整的暗色调、亮色调和灰色调色阶，每个色阶都带有一个**添加到调色板**按钮。 |

色轮和配色色板（排列在色轮外围的小圆点）的行为并不相同，值得把两者区分开来：

- **色轮区域不是色板**。拖动它会设置当前所选配色圆点的颜色；它没有单独的双击
  操作。
- **单击某个配色圆点会立即用该圆点的颜色绘制**，不改变圆点的颜色，色轮和圆点
  都不会有任何变化，改变的只有你的画布。
- **改为双击圆点来采用它的颜色**，这会使它成为你的当前颜色而不绘制任何内容。
  键盘操作的效果相同：用 Tab 把焦点移到某个圆点上，再
  按 **Space** 或 **Enter** 即可采用它。

因此，单击用于在不影响当前颜色的前提下，随手用某个配色颜色绘制；而要把它确定
为当前颜色，则应双击圆点，或者对已获得焦点的圆点使用 Space / Enter 来完成。
在色轮上移动时，配色会实时重新生成。

## 应用与保存

- **选取**：选中的颜色会立即成为当前颜色，当前颜色色板也会反映它，因此你的下
  一笔会使用它。
- **添加到收藏夹**：保存你常用的颜色以备日后使用。

## 调色板与索引文档

颜色中心与文档的**调色板**协同工作。在**索引**文档中，调色板是图像所用颜色的
固定集合；你可以把 `.gpl` / `.hex` / `.pal` 文件拖到窗口上来加载调色板（参
见[拖放导入](drag-drop-import.md)）。替换调色板是一个可撤销的步骤。

## 相关主题

- 在[画布](canvas-and-view.md)上用你选定的颜色绘制。
- 在 RGBA 与索引颜色模式之间转换，请使用**调色板**菜单中
  的**转换为 RGBA** 和**转换为索引色**；它对图层有何影响，参
  见[图层面板](layers.md)。
