# 动画时间轴

**动画系统**会把文档的帧列表变成一条*时间轴*：你可以添加、移除、重新排序和复制
帧，为每一帧单独设置在屏幕上的显示时长，用四种模式之一播放序列，通过洋葱皮查看相
邻的帧，还可以用帧标签把一段段帧范围组成**命名动画**。每一次帧编辑和标签编辑都是
单个撤销步骤。

在时间轴、播放、洋葱皮和标签方面，它达到了与 **Aseprite** 相当的水平，并通过帧标
签更进一步，支持**在同一个文件中包含多个相互独立的命名动画**（例如行走、奔跑、待
机）。

> **每一帧的图层相互独立**。每一帧都有**单独的**图层堆栈，并使用相同
> 的[图层引擎](layers.md)合成（可见性 / 不透明度 / 混合模式 / 图层组 / 蒙版都会
> 按帧生效）。在**索引**文档中，每一帧是单个索引图层，也不会显示洋葱皮（合成器仅
> 支持 RGBA 格式）。

## 帧条

**时间轴**面板把文档显示为一条水平的帧条，帧按播放顺序从左到右排列；每个单元格都
带有缩略图、帧号以及覆盖它的标签标记。图层面板会显示当前帧的图层。

- **选择帧**：单击某一帧（或使用方向键）。画布会显示该帧合成后的图层堆栈。选择帧
  属于视图操作，因此**不可**撤销。
- **拖动浏览**：在帧条上按住并拖动，画布会持续显示光标下方的帧。拖动浏览同样**不
  可**撤销。

## 管理帧

时间轴工具栏用于编辑帧序列。每个操作都**只算一个撤销步骤**：

| 操作 | 作用 |
| --- | --- |
| **添加帧** | 在当前帧之后插入一个新帧，其图层均为空。 |
| **移除帧** | 删除当前帧。**只剩一帧时不可用**：文档始终至少保留一帧。 |
| **复制帧** | 在源帧之后插入一个**独立的深层副本**，其图层和时长都会一并复制。编辑副本不会改变原帧。 |
| **拖动帧** | 把单元格拖到新位置即可**重新排序**。播放和拖动浏览都会按新的顺序进行。 |

撤销会精确恢复先前的帧序列，包括内容、顺序和时长。

## 每帧时长

每一帧都有单独的**时长**，单位为毫秒，显示在帧条的时长编辑框中（新帧默认使用标准
帧时长）。输入新值并提交（按 Enter 或移开焦点），即可设定这一帧的停留时间，这是
一个撤销步骤。时长必须是**正数**，非正数的值会被拒绝。播放时，时长为 500ms 的帧
停留的时间大约是时长为 100ms 的帧的五倍。

> **统一帧率**。统一的 FPS 只是为每一帧设置相同的时长，
> 即 `duration_ms = round(1000 / fps)`。播放计时始终只以每一帧的毫秒数为准。

## 播放

**播放控件**控制显示的帧如何随时间推进：

- **播放**会在整个文档范围内开始（或从暂停处恢复）。
- **暂停**会停在当前帧。
- **停止**会终止播放，并回到你开始播放时所在的帧。
- **Space** 用于切换播放 / 暂停。

**播放模式**选择器决定帧序列如何推进（默认为**循环**）：

| 模式 | 在 4 帧范围内的表现 |
| --- | --- |
| **循环** | `0,1,2,3,0,1,2,3,…`，永远循环。 |
| **单次** | 播放 `0,1,2,3` 之后会在最后一帧**停止**。 |
| **反向** | `3,2,1,0,3,2,1,0,…`，向后循环。 |
| **往返** | `0,1,2,3,2,1,0,1,2,3,…`，来回播放；**两端的帧不会连续出现两次**。 |

播放按每一帧的时长进行，所以修改某一帧的时长，会在下一轮播放时改变这一帧在屏幕上
的显示时间。

> **大型动画首次播放时，会在主线程之外做准备**。首次在大型的多图层文档（例
> 如 8K 画布）上播放某个范围时，每一帧拼合后的合成图像都需要先生成一次。这项工作
> 在 **GUI 线程之外**进行，状态栏中会出现一条小型的、**可取消**的进度条，窗口始
> 终保持响应，播放会随着帧准备完成而**流式推进**，而不是卡住不动。帧准备完成之后
> 会被缓存，因此重新播放和拖动浏览都能以 60fps 运行。

## 洋葱皮

洋葱皮会把**相邻的帧**显示在你正在编辑的帧下方，帮助你对齐动作。

- 通过洋葱皮面板中的**启用洋葱皮**复选框来**启用**它。虚影帧会渲染在当前帧下方，
  当前帧不会改变。
- 设置要显示多少个**前面**和**后面**的帧（把其中一项设为 `0` 即可关闭它；默认
  为**前面 1 帧 / 后面 1 帧**）。
- 为前面和后面的帧设置**色调**：默认前面的帧为**红色**，后面的帧为**蓝色**。更远
  的帧会渐渐淡出。

洋葱皮的帧数和色调属于**视图设置**：更改它们会实时更新浮层，并**不会**产生撤销步
骤。洋葱皮会在**播放时被隐藏**（它是编辑辅助，不是预览），拖动浏览时也同样隐藏。

## 帧标签（命名动画）

**帧标签**会把一段帧范围命名为一个独立的动画。一个文件可以包含多个标签，例如名
为 `walk` 的标签覆盖第 1–4 帧，名为 `idle` 的标签覆盖第 0 帧，这些标签还可以相互
重叠。

在**帧标签**面板中可以进行以下操作：

- **添加标签 / 编辑标签**：都会打开一个对话框，用于设置标签的**名称**、**起始
  帧 / 结束帧**范围（两端都包括在内）、**播放模式**、**重复次数(`0` = 无
  限)**（对循环类模式有效）和**颜色**。**移除标签**会立即删除所选标签，不显示对
  话框，仅在选中标签时可用。每次更改都是**一个撤销步骤**。标签会显示为一条覆盖相
  应帧的条带。
- **播放标签**会把所选标签作为独立的命名动画来播放：它按**标签自带的**播放模式和
  重复次数运行标签范围，与全局播放模式无关。**单次**标签的重复次数为 3 时，会把
  它的范围播放三次后停止。

添加或移除帧时，标签范围会自动保持有效（被限制在新的帧数之内）；撤销会同时恢复帧
的更改和原来的标签范围。

## 网格视图（画格网格）

时间轴工具栏中的**网格视图**开关会把水平的帧条切换为**画格网格**：帧为列，图层轨
道为行，样式与 Aseprite 的画格网格相同。它显示的还是帧条所显示的同一个文档，来回
切换不会丢失你当前所在的位置。

- **移动 / 复制画格**：按住并拖动含有画格的单元格，即可把它移到新的帧或轨道；拖
  动时按住 **Ctrl** 则改为复制，并把源画格留在原处。两者都是单个撤销步骤。这与画
  布上的 **Ctrl+drag** 是**不同**的手势，后者还是用于复制浮动选区，参
  见[选区与浮动移动/复制](selection-and-transform.md#copy-instead-of-move-hold-ctrl)。
  修饰键相同，不过具体生效的是哪一种手势，取决于你在哪里拖动。
- **覆盖确认**：把画格放到已有画格的单元格上时，会显示对话框**覆盖现有画格?**，
  你可以勾选其中的“**此项目不再询问**”复选框，这样在本项目中不会再被询问；如需重
  新启用这项确认，参见下文的[项目确认](#project-confirmations)。
- **切换画格可见性**：单击单元格的可见性指示器即可显示或隐藏对应帧的图层，这是一
  个撤销步骤，与其他任何位置的可见性开关相同。
- **在此创建画格**：在空单元格上右键单击（或按键盘上的上下文菜单键），即可使
  用“**在此创建画格**”操作。单元格已被占用，或对应的帧已达到图层数上限时，这个操
  作根本不会出现：菜单不会列出一定会被拒绝的操作。
- **拖动浏览**：在空的网格单元格上拖动，即可浏览每一帧，与在帧条上拖动一样。
- **重新排序列**：拖动列标题即可重新排序帧，这是网格中与拖动帧条单元格等效的操
  作。

### 项目确认

网格视图的覆盖确认是应用中按项目保存的首选项之一：用“此项目不再询问”关闭后，它在
该项目中会一直保持关闭，直到你从**编辑 ▸ 项目确认**中恢复它。该菜单会列出所有已
关闭的确认，并可分别重新开启。

## 指针手势

除了上文[管理帧](#managing-frames)中的工具栏按钮之外，帧条还响应四种配
合 **Ctrl** 使用的指针手势：

| 手势 | 结果 |
| --- | --- |
| **Ctrl+wheel** | 在当前文档中切换到下一帧 / 上一帧。 |
| **Ctrl+middle-click** | 直接跳到当前文档的第 1 帧。 |
| **Ctrl+left-click** | 在当前帧之后添加一帧，与**添加帧**按钮的操作相同，同样可以撤销。 |
| **Ctrl+right-click** | 删除当前帧，与**移除帧**按钮的操作相同，同样可以撤销，并**仅限时间轴**：网格视图中没有对应的操作。与该按钮一样，对文档仅剩的最后一帧会被拒绝，因为文档始终至少保留一帧。 |

## 保存与重新打开

帧、每帧时长和帧标签都会随 `.pixproj` 文件保存并读回。保存后再重新打开带标签的动
画，会原样恢复帧的顺序、每一帧的时长以及全部标签。先前版本（尚无标签功能时）保存
的项目还是可以打开，它们加载后标签集合为空。

## 撤销、重做与*不可*撤销的操作

- **可撤销（每项一步）**：添加 / 移除 / 重新排序 / 复制帧，设置帧的时长，创
  建 / 编辑 / 删除标签，以及在网格视图中移动 / 复制画格、切换画格的可见性和创建
  画格。
- **不可撤销（视图状态）**：选择或拖动浏览帧，播放 / 暂停 / 停止，更改洋葱皮的帧
  数或色调，以及在帧条和网格视图之间切换。
