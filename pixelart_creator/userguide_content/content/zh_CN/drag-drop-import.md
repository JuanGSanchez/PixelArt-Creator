# 拖放导入

把文件直接从操作系统的文件管理器（在 Windows 上是资源管理器，在 macOS 上是访达，
在 Linux 上是 Nautilus 程序）拖**进** PixelArt Creator 窗口，应用会按你预想的方
式处理这类文件。你不需要再一级级打开菜单（文件 ▸ 打开）：把文件放在窗口的任何位
置，应用都会**按文件类型**来决定处理方式，而不取决于你在窗口的哪个位置松开鼠标。

> **处理方式只取决于文件类型，与放置位置无关**。图像*总是*作为新文档打
> 开，`.pixproj` *总是*作为项目打开，调色板文件*总是*加载到当前调色板中，无论你
> 把它放在窗口的任何位置。一次拖放中可以混合多种类型，也可以同时放入多个文件。

## 拖入图像 → 新文档标签页

拖入 **`.png` / `.jpg` / `.jpeg` / `.bmp` / `.gif`** 文件，它会在一个**全新的画
布 / 文档标签页**中打开，并成为当前标签页。它会被导入为新文档，而**不是**当前正
在编辑的文档的一个图层，你当前的文档不会受到影响。

- 新文档为 **RGBA** 模式，宽高与图像一致。带调色板的索引模式 PNG 或 GIF 图像在导
  入时会转换为 RGBA 格式。
- 对于**动画 GIF 文件**，只会导入**第一帧**。
- 导入是**只读**的：拖入文件不会修改源文件。

> **图像尺寸限制**。大于画布最大尺寸 **7680 × 4320** 的图像会被**拒绝**并显示错
> 误提示，不会被悄悄裁剪或缩放。请先在应用之外转换它，或调整其大小。

## 拖入 `.pixproj` → 打开项目（防止丢失未保存的更改）

拖入 **`.pixproj`** 文件，它会作为项目打开。

如果你当前正在编辑的文档有**未保存的更改**，应用会先显示一个**保存 / 丢弃 / 取
消**对话框，以防你不小心丢失工作内容：

| 选项 | 结果 |
| --- | --- |
| **保存** | 保存当前文档，再打开拖入的项目。 |
| **丢弃** | 不保存，直接打开拖入的项目。 |
| **取消** | 中止打开，不会有任何改变。 |

如果当前文档**没有**未保存的更改（或者根本没有打开的文档），项目会立即打开，不显
示任何对话框。

## 拖入调色板 → 加载到当前调色板（可撤销）

拖入调色板文件，支持 **`.gpl` 格式（来自 GIMP 程序）、`.hex` 格式（仅十六进制颜
色的列表）和 `.pal` 格式（即 JASC-PAL 文本）**；文件中的颜色会**替换**当前文档的
调色板。

- 替换操作是**单个可撤销的步骤**：一次**撤销**即可精确恢复你之前的调色板。
- 如果没有打开任何文档，这次拖入不会产生任何影响，只会显示一条简要的提示。

> **支持哪些调色板格式**？调色板格式限于像素画中常见的**文本**格式，
> 即 `.gpl` / `.hex` / `.pal` 三种。而 Adobe 的 **`.aco`** 和 Aseprite 原生
> 的 **`.aseprite`** 这两种二进制格式**尚不支持**，目前会被报告为不支持的类型。

## 一次拖入多个文件

一次拖入多个文件时，每个文件都会**按拖入的顺序、根据其类型独立处理**：

- 多张图像 → 多个新标签页；
- `.pixproj` 会被打开（同样会在有未保存更改时先询问）；
- 调色板会依次加载：**最后**拖入的调色板最终成为当前调色板（每一次加载都是独立的
  撤销步骤）。

这一批文件中无法识别或无法读取的文件会被跳过并给出提示，其他文件还是会继续处理。
拖入 0 个文件时不会有任何反应。

## 文件无法导入时

拖放导入不会导致应用崩溃：

- **不支持的类型**（例如 `.txt` 文件，或 `.aco` / `.aseprite` 调色板）会被**忽
  略**，并显示一条简要、不会打断操作的状态提示；
- **损坏、无法解码或尺寸过大**的图像、**格式错误**的调色板，或**无
  效**的 `.pixproj` 文件，会显示**错误提示**，指明文件和问题所在，你的工作会**保
  持原样**：不会留下半成品的标签页，也不会留下加载到一半的调色板。

所有对话框和提示都可以翻译、可以通过键盘访问，并在浅色和深色主题下都保持可读。

## 未涵盖的内容

- **作为图层导入**：图像总是作为新文档打开，不会作为当前文档的图层。
- 对带调色板的源图像进行**索引导入**：图像会解码为 RGBA 格式；如果你需要索引文
  档，请在导入之后执行**调色板 ▸ 转换为索引色**（参见[图层](layers.md)）。
- **动画 GIF 导入**：只会导入第一帧。
- 管线中**导出 / 保存**的部分，参见[导出与管线集成](export-and-pipeline.md)。
