# AI 助手：用聊天驱动编辑器

**AI 助手**使你可以用**日常语言**来驱动编辑器。你在聊天面板中输入想要做的事，助手会
通过运行应用**自带的**操作来完成——即你可以手动录制、编写脚本和批量运行的同一
批[自动化](automation-and-scripting.md)命令。它是**与模型无关的**：你可以把它指向任
何你选择的 AI 服务商，并输入你个人的密钥。它也是**可选的**——不配置它，应用也完全可以
使用。

> **助手通过安全的自动化层行事——不会开放任何新功能**。助手所做的每个操作，都是一个正
> 常的、在允许列表内的编辑器操作，通过宏和脚本所使用的**同一个受信任的、不
> 含 `eval` 的命令层**来分发。它不能运行任意代码，不能在该命令层之外行事，也不能凭空
> 产生新的权限——聊天消息是**数据**，永远不是去做编辑器本来无法安全完成之事的许可。

## 打开助手

从**帮助 ▸ AI 助手**打开聊天面板。它会显示为一个**可停靠的面板**，你可以把它放在画布
附近，这样在助手工作时，你的作品也保持可见。面板会显示正在进行的对话——你的消息、助手
的回复，以及它对文档所做的编辑。

在助手可以与某个服务商通信之前，你需要先**配置一个**（见下文）。在此之前，它会处于明
确的**未配置**状态，而不是出错——配置服务商只需要做一次。

## 配置服务商和密钥

选择 AI 助手面板中的按钮**配置…**，可以打开服务商配置对话框。助手是**与模型无关
的**，所以你可以选择适合你的服务和模型，并输入：

| 字段 | 填写内容 |
| --- | --- |
| **服务商** | 一种是**兼容 OpenAI** 的服务，另一种是 **Anthropic (Claude)**。兼容 OpenAI 的选项涵盖多种端点，包括 OpenAI 的原生端点和 Gemini 的 OpenAI 兼容端点，以及 Ollama 或 llama.cpp 这类本地运行时；而 Anthropic 选项则以原生方式与 Claude 通信。 |
| **端点 URL** | 服务的 API 端点。你可以把它指向托管的服务商，也可以指向你机器上运行的本地模型服务器。 |
| **模型** | 要使用的模型名称，以你所选服务商给出的名称为准。 |
| **API 密钥** | 你为该服务商准备的密钥。即使是本地模型服务器，也必须保存一个密钥：只有当端点和一个非空的密钥都已保存时，助手才会认为某个服务商已配置，同时它会把你输入的内容原样发送，不做任何检查。如果你的本地服务器不检查密钥，请输入它能接受的任意非空文本。 |

选择**保存**，即可存储服务商设置。

> **你的密钥会被安全地存储——绝不会存放在你的项目中**。你输入的 API 密钥会被交给**操
> 作系统的安全凭据存储（操作系统密钥环）**。它**绝不会写入你的 `.pixproj` 项目文
> 件、绝不会被记入日志，也绝不会随共享或导出的项目一起传输**。因此，把项目分享给别
> 人，永远不会同时分享你的密钥。实时的密钥访问使用一个可选的扩展，通
> 过 `pip install ".[assistant_live]"` 安装，参见 README 文件。

> **凭据可选**。助手完全需要你主动启用。如果你从不配置服务商，编辑器的其他部分不会有
> 任何变化——你只是不使用助手而已。没有强制登录，使用 PixelArt Creator 也不需要任何密
> 钥。

## 通过聊天驱动工作流程

保存了一个服务商的设置之后（一个端点和保存在你的密钥环中的 API 密钥），用日常语言输
入一条消息——例如请助手重新为某个区域着色，或生成一些程序化内容——并发送出去。助手会解
读你的消息，确定哪些编辑器操作可以实现它，并运行这些操作，在对话记录中向你报告它做了
哪些事。因为它所运行的是**真实的**编辑器操作，所以结果与你手动执行这些步骤完全一样。

一次模型往返会在**后台工作线程**上运行，所以在助手工作时，窗口还是保持响应。

## 分级安全——可撤销的操作自动运行，破坏性的操作先询问

助手会把它想要执行的每个操作分入两个级别之一，由级别决定是否需要你的确认。这道关卡存
在于应用自带的代码中——它**不是**由 AI 模型决定的，聊天消息里的任何说法也无法使编辑器
跳过它。

- **可撤销的操作会直接应用**。一个以单个、可以完全撤销的步骤进入正
  常[撤销历史记录](app-basics.md)的操作（例如批量重新着色或程序化填充），会**无需询
  问即可直接应用**。你能看到它在文档中发生，也可以像撤销其他任何编辑一样**撤销它**。
- **破坏性的操作会先询问**。任何不在可撤销清单上的操作，都会被**默认视为破坏性
  的**，助手会**暂停并询问你**，并指明具体的操作。它**只有**在你确认时才会运行，否则
  会被取消——破坏性的操作绝不会被悄悄地应用。

> **默认安全**。这道关卡对任何它不能明确认定可以完全撤销的操作，默认都是*询问*。这表
> 示，一个新的或不常见的操作，绝不会仅仅因为没有人对它分类而自动运行——可撤销的级别是
> 一个小的、明确的集合，其他一切都要先通过一次确认提示。

## 助手不会做的事

- **它不能运行任意代码**。助手只通过受信任的命令层来驱动编辑器中在允许列表内的操
  作；这条路径上不存在 `eval`/`exec` 的调
  用，与[宏和脚本](automation-and-scripting.md)完全一样。
- **它不能跳过确认关卡**。没有任何指令——包括出现在工具结果中的指令——能使破坏性的操作
  跳过它的确认，也没有任何未获许可的操作，会仅仅因为对话中提到它而被运行。
- **它绝不会使你的密钥外传**。你的凭据保存在操作系统密钥环中，只用于与你所配置的服务
  商通信。

## 无障碍、主题与语言

助手面板和服务商对话框中的每个控件都有无障碍名称，并可以通过键盘访问；所有标签都完全
可翻译，并会在你切换语言时实时重新翻译；这两个界面在浅色和深色主题下都能正确显示。

## 相关主题

- 助手所运行的，是[自动化系统](automation-and-scripting.md)其他部分所使用的同一批操
  作——宏、脚本、批量重新着色和程序化生成。
- 配置服务商时采用的，是与[云端存储](cloud-and-collaboration.md)层中真实服务商相同的
  模式：凭据可选，并由密钥环支持（在当前版本中，它们无法从云端菜单中选择）。
