# 混合模式

每个图层（以及图层组）都使用一种**混合模式**进行合成，该模式可
从[图层面板](layers.md)中每个图层自带的下拉列表里选择。
在 PixelArt Creator 中共有 **12 种**模式：**正常**模式，加
上 W3C *Compositing and Blending Level 1* 标准中除正常外的 11 种**可分离**模式
（与 Photoshop / Krita / SVG 的模式集合和结果相同）。

混合在归一化的浮点工作空间中，基于**非预乘的直通 Alpha** 进行，再写
回 8 位 RGBA 格式。**正常**模式即直通 Alpha 的 source-over 合成。

## 12 种模式

| 模式 | 效果 |
| --- | --- |
| **正常** | 直通 Alpha 的 source-over 合成。完全不透明的图层会取代下方内容；完全透明的图层则保持下方内容不变。 |
| **正片叠底** | 将图层与下方内容相乘，总是变暗。白色为中性色；黑色得到黑色。 |
| **滤色** | 与正片叠底相反，总是变亮。黑色为中性色；白色得到白色。 |
| **叠加** | 暗调部分按正片叠底处理，亮调部分按滤色处理，提高对比度（相对于下方内容）。 |
| **变暗** | 保留两个通道值中较暗的一个。 |
| **变亮** | 保留两个通道值中较亮的一个。 |
| **颜色减淡** | 提亮下方内容以反映图层，提亮明显。 |
| **颜色加深** | 使下方内容变暗以反映图层，变暗明显。 |
| **强光** | 叠加模式中图层与底层的角色互换，如同刺眼的聚光灯。 |
| **柔光** | 更柔和的强光，按图层的数值进行减淡或加深。 |
| **差值** | 取两个值之差的绝对值，相同的颜色结果为黑色。 |
| **排除** | 与差值相近，只是中间调的对比度更小。 |

> **不透明度与混合模式共同作用**。图层的不透明度会缩放它对合成结果的影响，
> 对**每一种**混合模式都是如此，而不仅限于正常模式。隐藏
> 的图层无论采用何种模式，都不会产生任何影响。

## 图层堆栈如何合成

图层**自下而上**合成到一个持续更新的结果上：每个可见图层的像素都会按该图层的
混合模式和不透明度（如果有蒙版，还有蒙版）混合到下方内容之上。由正常图层组成
的堆栈，与自下而上逐层做直通 Alpha 的 source-over 合成完全相同。合成绝不会
修改源图层的缓冲区，因此是非破坏性的。

单次编辑只会重新合成**受影响的区域**，因此在大画布上绘制也能快速响应。

## 性能

在 7680 × 4320 的 8K 画布上，单像素绘制重新合成其发生变化的小片区域，大约只
需 **1ms** 的时间，完全处于 16ms / 60fps 的帧预算之内。在缩放比例较小时，一
些较重的操作，例如拖动不透明度滑块，或是需要跨多个图层重绘大片视口的属性更
改，目前受限于 CPU 性能，可能超出预算；完整的 GPU 着色器合成留到以后实现。
