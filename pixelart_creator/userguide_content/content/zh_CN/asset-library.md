# 素材库：浏览、标记与搜索

**素材库**是一个跨项目的目录，把你可复用的素材——精灵、动画、瓦片集、瓦片地图和调色
板——集中在一处。把你已制作的对象登记为**有名称的素材**，用自由格式的**标签**整理它
们，并通过**搜索和筛选**快速找到合适的一个。素材库及其三个面板都从**素材库**菜单进
入。

> **何为素材**。素材是一个**目录条目**，它*引用*你已创作的某个对象——它不会再制作一个
> 你作品的副本。每个条目都带有一个**稳定的标识**、一个**类型**（精灵、动画、瓦片
> 集、瓦片地图或调色板）、一个显示用的**名称**、它的**标签**，以及少量元数据。条目指
> 向该对象的标准保存形式（应用其他部分所使用的同一种 `.pixproj` 数据）——素材库不会为
> 作品添加任何新的保存格式。

## 打开素材库

**素材库**菜单中为这三个面板分别有一个停靠开关，每个开关用于显示或隐藏一个面板：

| 菜单项 | 面板 | 作用 |
| --- | --- | --- |
| **素材库** | 目录列表 | 按名称、类型和标签浏览每一个素材。 |
| **素材搜索** | 搜索 / 筛选控件 | 按名称、标签和 / 或类型缩小列表范围。 |
| **素材标记** | 标签编辑器 | 为所选素材添加和移除标签。 |

每个菜单项都是一个标准的停靠开关（与应用的其他工作流程面板一致），所以你可以按适合你
的方式排列这三个面板。这些面板共用**同一个**内存中的目录，所以在一个面板中所做的更改
会即时反映在其他面板中。

## 登记素材

在任何内容出现在目录中之前，它必须先被**登记**。应用中有三个地方会开始登记，三者都会
进入同一个共用的**登记素材**提示：

- **登记当前文档**位于**素材库**菜单中，会登记当前标签页中打开的文档。以后再次登记同
  一个文档，会在它已有的目录条目上追加一个新修订，而不是创建重复的条目——参
  见[素材版本管理与跨项目复用](asset-versioning.md)。
- **登记选区**同样位于**素材库**菜单中，只会登记当前选区内部的像素。对于非矩形选
  区，登记后的素材中，所选像素之外的一切都是透明的。没有选区时，则没有可登记的内容。
- **同时添加到素材库**是导出对话框上的一个复选框（参
  见[导出与管线集成](export-and-pipeline.md)），它会在导出的同一步骤中，把导出的文件
  登记到素材库。

这三者都会打开同一个**登记素材**对话框，它会询问：

| 字段 | 询问内容 |
| --- | --- |
| **名称** | 新目录条目的显示名称。 |
| **类型** | 五种素材类型之一——精灵、动画、瓦片集、瓦片地图、调色板。 |
| **标签** | 可选的、用逗号分隔的一组标签，会按照与下面的标记面板相同的长度和数量上限进行检查。 |

对话框会在你输入时进行校验：名称为空，或者标签集超出长度 / 数量上限，会使**登记**按
钮被禁用，并显示一条明确的原因，直到你修正为止。取消对话框不会登记任何内容。

## 移入或移出单个素材

另外还有两个**素材库**菜单命令，用来移动单个素材文件，这与移动整个项目不同：

- **导出素材**会把当前选中的目录条目——或者在没有选中任何条目时，把打开的目录中的每一
  个条目——导出为一个可导入的素材文件。
- **导入素材**会把这样的素材文件读回到打开的素材库中，并合并进目录。

这两个命令与**导出项目包** / **导入项目包**是分开的，后者会移动整个项目及其引用的所
有内容——参见[素材版本管理与跨项目复用](asset-versioning.md)。

## 浏览目录

**素材库**面板用四列列出目录——**名称**、**类型**、**标签**和**状态**。它始终如实显示
目录中的内容：添加、移除或标记素材都会即时更新列表。选中一行即选中该素材，而**素材标
记**面板编辑的正是它。

- 列表完全由共享目录决定；面板不会自行做任何筛选或排序。
- 当**素材搜索**面板有生效的查询时，素材库列表只显示匹配的条目（见下文）；清除查询会
  恢复完整的列表。

## 标记素材

**素材标记**面板编辑素材库中所选素材的标签。输入一个标签并添加它；选中一个标签并移除
它。标签可以是任意自由格式的文字——例如 `hero`, `enemy` 或 `tileset-a`——使你可以按含
义来整理素材。

- **标签编辑可以撤销**。添加或移除一个标签，是共享撤销历史记录中的单个步骤，所以**撤
  销**会恢复先前确切的标签集，**重做**会重新应用这次编辑——与你在其他任何地方所用的撤
  销 / 重做完全相同（参见[入门与工作区](app-basics.md)）。
- **添加一个已存在的标签不会有任何效果**（它是空操作），而移除一个不存在的标签同样不
  会产生影响。
- **标签有上限**。单个标签有最大长度，每个素材的标签数量也有上限。过长的标签，或者会使素
  材超出标签数上限的标签，会被**拒绝并给出明确的消息**，不会被添加——不会有任何内容被
  悄悄缩减。

## 搜索与筛选

**素材搜索**面板用三个协同工作的控件来缩小素材库列表的范围：

| 控件 | 匹配依据 |
| --- | --- |
| **名称** | 名称*包含*你所输入文本的素材（子串匹配）。 |
| **标签** | 带有你输入的标签的素材（输入多个标签时用逗号分隔）。 |
| **类型** | 属于所选类型的素材；**所有类型**条目会清除类型筛选。 |

- 这三个筛选条件会**取交集**——一个结果必须匹配你设置的名称，*同时*匹配标签，*同时*匹
  配类型。把某个控件留空，会忽略该控件所对应的维度。
- **结果是稳定而确定的**：相同的目录和相同的查询，总会产生相同顺序的相同列表。
- **清除所有控件会恢复完整的目录**，并按其正常顺序显示。

> **按含义查找，而不是按文件查找**。由于素材有标签并可以搜索，你可以调出“每一
> 个 `enemy` 精灵”或“带有 `dungeon` 标签的瓦片集”，而不必在文件夹中翻找。给素材使用
> 一小套前后一致的标签，剩下的交给筛选器即可。

## 素材的存储方式

在这些面板背后，素材库保存着一个素材条目的**目录**，以及一个存放其字节的**按内容寻址
的存储**：

- **按内容只存储一次**。每个素材的字节都以*内容*为键存储，所以两次登记相同的内容不会
  产生重复——相同的字节只保留一次（**去重**）。
- **通过稳定的标识引用，而不是通过路径**。素材由随它一起移动的稳定标识来识别，所
  以**移动或重命名**底层文件**不会**破坏目录条目。
- **作品保持其正常的保存格式**。目录复用现有的 `.pixproj` 项目格式来存放数据，并只另
  外存放引用和元数据——你不需要为作品再操心第二种格式。
- **加载是防御式的**。加载时，目录或其元数据会被视为不可信的输入：会检查它的大小和结
  构，绝不会执行任何内容，并会确认每一个被引用的路径都停留在素材库之内——格式错误或超
  出范围的目录会被拒绝并给出明确的错误，而不会导致崩溃或破坏任何内容。

## 素材库的其他部分

素材库是分阶段发布的；这一阶段的全部内容现在都已发布。除了上面的目录、标记以及搜
索 / 筛选之外：

- **[素材依赖关系与失效检测](asset-dependencies.md)**——一个可查询的图，说明素材之间
  如何相互引用，例如 `sprite -> animation -> tileset -> tilemap` 这样的链条，以及当
  某个素材发生更改会破坏另一个引用它的素材时给出的被动警告。
- **[素材版本管理与跨项目复用](asset-versioning.md)**——每个素材一个仅追加的修订历史
  记录（可查看和还原）、跨项目对共享素材的引用而非复制式复用、把项目所引用的素材作为
  自包含的包导出 / 导入，以及对共享数据块的可选云端后备存储（在当前版本中未接通）。
